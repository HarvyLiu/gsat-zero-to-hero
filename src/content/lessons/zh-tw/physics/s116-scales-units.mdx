## 大家共用的尺：國際單位制

測量就是拿一個約定好的「單位」去比。如果每個國家、每間實驗室的單位都不一樣，結果就無法互相比較，所以全世界的科學界共用<Term t="physics.si-units">國際單位制</Term>，簡稱SI。它選定七個**基本量**，每個基本量有一個**基本單位**：

| 基本量 | 基本單位 | 符號 |
|---|---|---|
| 長度 | 公尺 | $\mathrm{m}$ |
| 質量 | 公斤 | $\mathrm{kg}$ |
| 時間 | 秒 | $\mathrm{s}$ |
| 電流 | 安培 | $\mathrm{A}$ |
| 溫度 | 克耳文 | $\mathrm{K}$ |
| 物質的量 | 莫耳 | $\mathrm{mol}$ |
| 發光強度 | 燭光 | $\mathrm{cd}$ |

太大或太小的數，用**字首**表示 $10$ 的次方，搭配<Term t="math.scientific-notation">科學記號</Term>一起用：

| 字首 | 吉 $\mathrm{G}$ | 百萬 $\mathrm{M}$ | 千 $\mathrm{k}$ | 厘 $\mathrm{c}$ | 毫 $\mathrm{m}$ | 微 $\mu$ | 奈 $\mathrm{n}$ | 皮 $\mathrm{p}$ | 飛 $\mathrm{f}$ |
|---|---|---|---|---|---|---|---|---|---|
| 代表 | $10^{9}$ | $10^{6}$ | $10^{3}$ | $10^{-2}$ | $10^{-3}$ | $10^{-6}$ | $10^{-9}$ | $10^{-12}$ | $10^{-15}$ |

把這些字首排到以 $10$ 的指數為刻度的數線上，就看得出規律：除了厘 $\mathrm{c}$ 以外，相鄰的字首都差 $3$ 格，也就是差 $10^{3}=1000$ 倍。

<NumberLine desc="以 10 的指數為刻度的數線，從 −15 到 9，刻度 n 代表 10ⁿ。標出各字首代表的指數：飛 f（−15）、皮 p（−12）、奈 n（−9）、微 μ（−6）、毫 m（−3）、厘 c（−2）、千 k（3）、百萬 M（6）、吉 G（9）。除了厘以外，相鄰的字首都相隔 3 格，也就是差 1000 倍。" from={-15} to={9} step={1} labelEvery={3}
  points={[{ x: -15, label: 'f' }, { x: -12, label: 'p' }, { x: -9, label: 'n' }, { x: -6, label: 'μ' }, { x: -3, label: 'm' }, { x: -2, label: 'c' }, { x: 3, label: 'k' }, { x: 6, label: 'M' }, { x: 9, label: 'G' }]} />

所以原子約 $10^{-10}\ \mathrm{m}=0.1\ \mathrm{nm}$，原子核約 $10^{-15}\ \mathrm{m}=1\ \mathrm{fm}$。

單位的定義也一直在進步，目標是讓任何實驗室都能自己精準地重現它。現在的公尺是光在真空中 $\frac{1}{299792458}$ 秒內走的距離（1983年起），秒則由銫原子發出的輻射來定義。公斤從1889年起是保存在巴黎近郊國際度量衡局的一個金屬圓柱（國際公斤原器）的質量，2019年起改為固定普朗克常數的數值來定義，不再依賴任何實物。111學測第58–60題組就以這個新的質量標準和電磁天平為情境。

<StudentAsks q="為什麼質量的基本單位是公斤，而不是公克？">

這是歷史留下來的選擇：SI選定公斤當基本單位，所以七個基本單位裡只有它本身就帶字首 $\mathrm{k}$。這點很容易混淆：$\mathrm{kg}$ 是基本單位，$\mathrm{g}$ 不是；$\mathrm{km}$ 也不是基本單位，它只是基本單位 $\mathrm{m}$ 加上字首。

</StudentAsks>

### 換算單位：速率

**例題**　把 $36\ \mathrm{km/h}$ 換成 $\mathrm{m/s}$。

$1\ \mathrm{km}=1000\ \mathrm{m}$、$1\ \mathrm{h}=3600\ \mathrm{s}$，直接代進去：

$$
36\ \mathrm{km/h}=\frac{36\times 1000\ \mathrm{m}}{3600\ \mathrm{s}}=10\ \mathrm{m/s}
$$

<Perspective title="乘上「等於1的分數」：讓單位自己消掉">

$\dfrac{1000\ \mathrm{m}}{1\ \mathrm{km}}$ 的分子分母是同一段長度，所以它等於 $1$；乘上它不會改變大小，只會換單位。把單位當成可以約分的代數符號：

$$
36\ \frac{\mathrm{km}}{\mathrm{h}}\times\frac{1000\ \mathrm{m}}{1\ \mathrm{km}}\times\frac{1\ \mathrm{h}}{3600\ \mathrm{s}}=\frac{36\times 1000}{3600}\ \frac{\mathrm{m}}{\mathrm{s}}=10\ \mathrm{m/s}
$$

$\mathrm{km}$ 上下各一個、$\mathrm{h}$ 上下各一個，約掉後只剩 $\mathrm{m/s}$。如果你把分數擺反了，單位會變成 $\mathrm{km^{2}}$ 之類的怪東西，一眼就看得出錯。順帶得到捷徑：$\frac{1000}{3600}=\frac{1}{3.6}$，所以 $\mathrm{km/h}$ 的數字除以 $3.6$ 就是 $\mathrm{m/s}$。

<Graph desc="橫軸是以 km/h 表示的速率（0 到 120），縱軸是以 m/s 表示的同一個速率（0 到 40）。實線 y=x/3.6 是換算線，虛線 y=x 是對照線；換算線一直在對照線下方，表示 m/s 的數字總是比 km/h 的數字小。標出的點 (36, 10) 就是例題：36 km/h 對應到 10 m/s。" x={[0, 120]} y={[0, 40]} height={260}

  points={[{ at: [36, 10], label: '(36, 10)' }]} />

同一個速率，換成 $\mathrm{m/s}$ 時數字要變小（除以 $3.6$），因為 $1\ \mathrm{m/s}$ 比 $1\ \mathrm{km/h}$ 快；從圖上也看得出，換算線一直在 $y=x$ 的下方。

</Perspective>

## 許多物理量是「算」出來的

只有基本量需要直接拿標準去比；其他物理量大多是**由基本量的測量計算而得**，叫做導出量，它們的單位也是由基本單位組合而成：

| 導出量 | 怎麼算 | SI單位 |
|---|---|---|
| 面積 | 長度 × 長度 | $\mathrm{m^{2}}$ |
| 體積 | 長度 × 長度 × 長度 | $\mathrm{m^{3}}$ |
| 密度 | 質量 ÷ 體積 | $\mathrm{kg/m^{3}}$ |
| 速率 | 距離 ÷ 時間 | $\mathrm{m/s}$ |
| 頻率 | 每秒振動的次數 | $\mathrm{Hz}=\mathrm{1/s}$ |

之後的章節會遇到的力的單位牛頓和能量的單位焦耳，也是由基本單位組合出來的：$\mathrm{N}=\mathrm{kg\cdot m/s^{2}}$、$\mathrm{J}=\mathrm{kg\cdot m^{2}/s^{2}}$。

**例題**　用尺量得一塊長方體鋁塊長 $2\ \mathrm{cm}$、寬 $3\ \mathrm{cm}$、高 $5\ \mathrm{cm}$，用天平量得質量 $81\ \mathrm{g}$。它的密度是多少 $\mathrm{kg/m^{3}}$？

體積是 $2\times 3\times 5=30\ \mathrm{cm^{3}}$，密度是

$$
\rho=\frac{81\ \mathrm{g}}{30\ \mathrm{cm^{3}}}=2.7\ \mathrm{g/cm^{3}}
$$

再換成SI單位。$1\ \mathrm{g}=10^{-3}\ \mathrm{kg}$，$1\ \mathrm{cm^{3}}=(10^{-2}\ \mathrm{m})^{3}=10^{-6}\ \mathrm{m^{3}}$，所以

$$
1\ \mathrm{g/cm^{3}}=\frac{10^{-3}\ \mathrm{kg}}{10^{-6}\ \mathrm{m^{3}}}=10^{3}\ \mathrm{kg/m^{3}},\qquad \rho=2.7\times 10^{3}\ \mathrm{kg/m^{3}}=2700\ \mathrm{kg/m^{3}}
$$

這裡真正「量」的只有長度（三次）和質量（一次），密度是算出來的。

<Perspective title="數方塊：為什麼是1000倍而不是100倍">

<Perspective later title="用單位檢查公式" needs="因次分析（選修物理內容，學測當作考試技巧）" href="/zh-tw/physics/s116-physics-reasoning/">

單位還能幫你抓錯：等號兩邊的單位必須相同。假設有人把密度寫成 $\rho=\frac{V}{m}$，右邊的單位是 $\mathrm{m^{3}/kg}$，和密度的 $\mathrm{kg/m^{3}}$ 不同，所以一定寫錯了。同樣地，「距離＝速率÷時間」的右邊是 $\frac{\mathrm{m/s}}{\mathrm{s}}=\mathrm{m/s^{2}}$，不是 $\mathrm{m}$，也錯了；改成「速率×時間」，單位就是 $\mathrm{m}$。

更完整的「因次分析」屬於選修物理，但學測曾用它設計題組，所以我們在考試技巧的章節再練習。單位對了不保證公式對，單位錯了卻一定是錯的。

</Perspective>

## 從原子核到宇宙

把東西的大小都寫成科學記號，比較尺度就只是比較 $10$ 的指數。下面的數線上，刻度 $n$ 代表 $10^{n}\ \mathrm{m}$，每往右一格（$5$）就放大 $10^{5}$ 倍：

<NumberLine desc="以 10 的指數為刻度的數線，刻度 n 代表 10ⁿ 公尺，從 −20 到 30，每 5 一格。標出的位置：原子核約 10⁻¹⁵ m（−15）、原子約 10⁻¹⁰ m（−10）、細胞約 10⁻⁵ m（−5）、人約 1 m（0）、地球直徑約 1.3×10⁷ m（約 7.1）、日地距離約 1.5×10¹¹ m（約 11.2）、銀河系約 10²¹ m（21）、可觀測宇宙的直徑約 9×10²⁶ m（約 26.9）。每往右 1 單位，大小就乘以 10。" from={-20} to={30} step={5}
  points={[{ x: -15, label: '原子核' }, { x: -10, label: '原子' }, { x: -5, label: '細胞' }, { x: 0, label: '人' }, { x: 7.1, label: '地球' }, { x: 11.18, label: '日地距離' }, { x: 21, label: '銀河系' }, { x: 26.9, label: '宇宙' }]} />

課綱要你記住兩個數：**原子約 $10^{-10}\ \mathrm{m}$，原子核約 $10^{-15}\ \mathrm{m}$**。

**例題**　$1\ \mathrm{mm}$ 長的線段上，大約可以排幾個原子？

$1\ \mathrm{mm}=10^{-3}\ \mathrm{m}$，所以個數約

$$
\frac{10^{-3}}{10^{-10}}=10^{-3-(-10)}=10^{7}
$$

也就是一千萬個。比較尺度時，前面的係數不精確沒關係，重點是 $10$ 的指數。

<Perspective title="在數線上量距離：指數差幾格，就差幾個10倍">

上面的數線每 $1$ 單位代表「乘以 $10$」。原子核在 $-15$，原子在 $-10$，兩者相距 $5$ 單位，所以原子是原子核的 $10\times 10\times 10\times 10\times 10=10^{5}$ 倍。不用做除法，只要數格子。

<NumberLine desc="刻度 n 代表 10ⁿ 公尺的數線，從 −16 到 −9。原子核在 −15，原子在 −10，中間塗色的一段長 5 單位，每 1 單位代表乘以 10，所以原子比原子核大 10⁵ 倍。" from={-16} to={-9} step={1}
  intervals={[{ a: -15, b: -10, color: 'amber' }]}
  points={[{ x: -15, label: '原子核' }, { x: -10, label: '原子' }]} />

剛才的例題也一樣：$1\ \mathrm{mm}$ 在 $-3$，原子在 $-10$，相差 $7$ 格，所以約 $10^{7}$ 個。這把「指數尺」其實就是對數尺：位置是 $\log$（大小），所以日地距離 $1.5\times 10^{11}\ \mathrm{m}$ 落在 $11+\log 1.5\approx 11.18$，比 $11$ 稍微右邊一點。

</Perspective>

<Perspective title="換成體積比：原子裡幾乎是空的">

直徑差 $10^{5}$ 倍，體積差多少？體積和長度的三次方成正比，所以

$$
\left(10^{5}\right)^{3}=10^{15}
$$

原子的體積大約是原子核的 $10^{15}$ 倍。用開頭的比喻：原子核是 $1$ 公分的彈珠，原子就是直徑 $1$ 公里的大球，大球裡只有正中央那顆彈珠，其餘幾乎都是空的。原子的質量卻幾乎都集中在原子核裡，下一章會再看到這個圖像。

</Perspective>

<StudentAsks q="宇宙那麼大，天文學家是怎麼量出這些距離的？">

靠的是一層一層的「量尺」，其中一把來自美國天文學家勒維特（Henrietta Leavitt）。她在哈佛大學天文台研究一類會週期性變亮變暗的恆星（造父變星），在1910年代初發現：越亮的造父變星，亮暗變化的週期越長。知道了週期就能推出它真正有多亮，再和看起來的亮度比較，就能推算距離。1920年代，哈伯用這個方法證明仙女座星系遠在銀河系之外，宇宙的尺度一下子大了許多。

</StudentAsks>

## 科學方法：從問題到預測

課綱把科學方法整理成五個步驟：**發現問題 → 提出假說 → 實驗分析驗證 → 建立理論 → 預測**。理論做出的預測又會帶出新的問題和實驗，所以它是一個循環。

原子核的發現正好走過這個循環：

1. **發現問題**：原子裡帶正電的部分是怎麼分布的？
2. **提出假說**：當時流行湯姆森的模型，認為正電荷均勻散布在整個原子裡。如果是這樣，打向原子的帶正電粒子只會被稍微推偏。
3. **實驗分析驗證**：1909年前後，出生於紐西蘭的拉塞福（Ernest Rutherford）在英國曼徹斯特帶領蓋革與馬士登，用帶正電的 α 粒子撞擊很薄的金箔。大多數粒子直直穿過，卻有極少數偏轉很大的角度，甚至反彈回來，和假說的預期不符。
4. **建立理論**：1911年拉塞福提出新的模型：原子的正電荷和大部分質量集中在中心一個非常小的原子核裡。
5. **預測**：新模型可以預測粒子往各個角度偏轉的比例，後續的實驗和預測相符；由散射的結果也能推知原子核比原子小得多。

<Perspective title="自己走一次：用密度判斷金屬的種類">

科學方法不只是大科學家的故事，本章的密度實驗就能完整走一次：

1. **發現問題**：手上這塊銀白色的金屬是什麼？
2. **提出假說**：它很輕，可能是鋁。
3. **實驗分析驗證**：量長度和質量，算出密度約 $2.7\ \mathrm{g/cm^{3}}$；量好幾塊再畫質量對體積的圖，斜率也約是 $2.7$，和鋁的密度相符。
4. **建立理論**（這裡是得到結論）：這種金屬的密度約 $2.7\ \mathrm{g/cm^{3}}$，與鋁一致。
5. **預測**：同材質、體積 $50\ \mathrm{cm^{3}}$ 的另一塊，質量應約 $2.7\times 50=135\ \mathrm{g}$。拿去秤，若真的約 $135\ \mathrm{g}$，結論又多了一次支持；若差很多，就要回到第一步重新想。

注意第3步只檢驗了「密度相符」。密度相同的材料不一定是同一種，所以結論要說得剛好，不要說過頭，這就是上一章說的「不急著下結論」。
