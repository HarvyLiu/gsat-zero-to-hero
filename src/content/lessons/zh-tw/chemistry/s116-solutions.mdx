## 溶液、膠體與懸浮液：看粒子大小

把一種物質分散到另一種物質裡，得到的是<Term t="chemistry.mixture">混合物</Term>。依照分散的粒子有多大，可以分成三類：

- **真溶液**：粒子直徑小於約 $10^{-9}$ 公尺（1奈米），是一個個分子或離子。<Term t="chemistry.solution">溶液</Term>由<Term t="chemistry.solute">溶質</Term>和<Term t="chemistry.solvent">溶劑</Term>組成：食鹽水中，氯化鈉是溶質，水是溶劑。溶液是均勻的混合物，不一定是液體：空氣和黃銅也是溶液。
- <Term t="chemistry.colloid">膠體</Term>：粒子直徑約在 $10^{-9}$ 到 $10^{-6}$ 公尺之間，常是很大的分子，或許多分子聚成的小團。例如牛奶、豆漿、霧和澱粉水。
- **懸浮液**：粒子直徑大於約 $10^{-6}$ 公尺，例如泥水。靜置後粒子會沉下來，也會被濾紙擋住。

真溶液和膠體靜置都不會沉降，也都能通過濾紙，所以光看外觀常分不出來。

<StudentAsks q="膠體是不是就是很稀的溶液？">

不是。分類看的是**粒子大小**，不是濃度。把澱粉水再稀釋十倍，每個粒子還是那麼大，仍然是膠體，光路變淡但還在；把食鹽水調得很濃，粒子仍是一個個離子，還是真溶液，照樣看不到光路。

</StudentAsks>

<Perspective title="量不到粒子大小時：用三個操作來分">

實驗室裡沒辦法直接量粒子直徑，可以改用三個簡單的操作，依序判斷：

1. **靜置**：粒子會沉下來 → 懸浮液。
2. 不沉降的，用**雷射光照**：從側面看得到光路 → 膠體。
3. 看不到光路 → 真溶液。

**例**　一杯混濁的泥巴食鹽水靜置一小時，杯底積了泥沙。它是懸浮液。再取上層的清液用雷射光照，從側面看不到光路，清液是真溶液（食鹽水）。同一杯東西，泥沙和食鹽分屬不同的大小等級。

這三個操作其實就是在比大小：會沉降，表示粒子大於約 $10^{-6}$ 公尺；會散射光，表示粒子至少有約 $10^{-9}$ 公尺。操作的結果和數線上的分段一一對應。

</Perspective>

真溶液裡的粒子是分子還是離子，也有差別。先想一想：食鹽水、糖水、鹽酸三杯真溶液，接上燈泡，哪幾杯會亮？

溶質若是<Term t="chemistry.ionic-compound">離子化合物</Term>，溶在水中會分開成可以移動的離子。[化學鍵](/zh-tw/chemistry/s116-chemical-bonds/)那一章看過：食鹽水能導電，糖水不能。溶在水中能導電的物質叫<Term t="chemistry.electrolyte">電解質</Term>，例如氯化鈉和氯化氫，所以食鹽水和鹽酸會亮；糖在水中仍是一個個分子，不是電解質。電解質導電的強弱，下一章再談。

## 濃度：每公升溶液裡有幾莫耳

國中學過兩種濃度，都是「溶質質量占溶液質量的比例」：

- 重量百分濃度＝$\dfrac{\text{溶質質量}}{\text{溶液質量}}\times100\%$
- <Term t="chemistry.ppm">百萬分點</Term>（ppm）＝$\dfrac{\text{溶質質量}}{\text{溶液質量}}\times10^{6}$，用在很稀的溶液。例如1公斤的水樣中含0.002公克某物質，就是 $\dfrac{0.002}{1000}\times10^{6}=2$ ppm。

化學反應是粒子和粒子在反應，所以化學更常用「每公升溶液裡有幾<Term t="chemistry.mole">莫耳</Term>溶質」，這叫<Term t="chemistry.molarity">體積莫耳濃度</Term>：

$$
C_M=\frac{n}{V}
$$

$n$ 是溶質的莫耳數，$V$ 是**溶液**的體積（公升），單位是 $\mathrm{mol/L}$，記作 $\mathrm{M}$。

<Predict id="sol-nacl-molarity" prompt="取Na＝23、Cl＝35.5。把5.85公克的NaCl溶成200毫升的溶液，體積莫耳濃度是多少M？" answer={0.5} unit="M">

$\ce{NaCl}$ 的<Term t="chemistry.molar-mass">莫耳質量</Term>是 $58.5\ \mathrm{g/mol}$，所以 $n=5.85\div58.5=0.100$ 莫耳。體積要換成公升：200毫升＝0.200公升。$C_M=0.100\div0.200=0.500\ \mathrm{M}$。如果你得到0.0005，是直接把200代進去了：分母一定要用公升。

</Predict>

把 $V$ 拉到0.25，讀出2 M那條線上有幾莫耳；再想想「0.6公升中有0.3莫耳」的溶液落在哪一條線上。先寫下答案再往下讀。

答案是0.5莫耳和0.5 M那條線：**每條線的斜率就是濃度**，同一瓶溶液取多取少，點都在同一條線上。

<StudentAsks q="把0.5莫耳的糖加進1公升的水裡，濃度就是0.5 M嗎？">

不是。$\mathrm{M}$ 的分母是**溶液**的體積，不是溶劑的體積。糖溶進去以後，溶液的體積不會剛好是1公升，所以濃度也不會剛好是0.5 M。要配出準確的濃度，得先讓溶質溶解，再加水到「溶液總體積」剛好1公升，這就是下一節的容量瓶。

</StudentAsks>

<Perspective title="倒出一杯：濃度不變，莫耳數變了">

濃度是一個比值，像配方：不管倒出多少，每公升裡的莫耳數都一樣。

**例**　一瓶1.00公升、0.50 M的食鹽水，倒出100毫升到杯子裡。

1. 瓶裡原本有 $0.50\times1.00=0.50$ 莫耳NaCl。
2. 杯子：濃度仍是0.50 M，莫耳數是 $0.50\times0.100=0.050$ 莫耳。
3. 瓶子剩900毫升：濃度仍是0.50 M，莫耳數是 $0.50\times0.900=0.45$ 莫耳。
4. 合起來 $0.050+0.45=0.50$ 莫耳，一個也沒少。

所以「這杯有多濃」問的是 $C_M$，「這杯有多少溶質」問的是 $n=C_M\times V$。在上一張圖上，杯子和瓶子是同一條0.5 M直線上的兩個點。

**附帶：兩種濃度怎麼互換**　重量百分濃度看質量，體積莫耳濃度看體積和莫耳數，兩者之間要靠**密度**把體積接到質量。某鹽酸的重量百分濃度是36.5%，密度是 $1.2\ \mathrm{g/mL}$。它的體積莫耳濃度是多少？（H＝1、Cl＝35.5）

1. 取1公升（1000毫升）溶液來算：溶液質量是 $1000\times1.2=1200$ 公克。
2. 其中氯化氫占36.5%：$1200\times0.365=438$ 公克。
3. $\ce{HCl}$ 的莫耳質量是 $36.5\ \mathrm{g/mol}$：$438\div36.5=12$ 莫耳。
4. 12莫耳在1公升溶液中，所以是12 M。

反過來驗算：1公升12 M的鹽酸含 $12\times36.5=438$ 公克氯化氫，溶液1200公克，$438\div1200=36.5\%$。兩種說法描述的是同一瓶溶液。

</Perspective>

## 配製與稀釋

**配製**　要配250毫升、0.20 M的氫氧化鈉溶液（Na＝23、O＝16、H＝1）：

1. 計算：$n=0.20\times0.250=0.050$ 莫耳；$\ce{NaOH}$ 的莫耳質量是 $40\ \mathrm{g/mol}$，所以要 $0.050\times40=2.0$ 公克。
2. 秤2.0公克 $\ce{NaOH}$ 放進燒杯，加少量水攪拌到完全溶解。氫氧化鈉溶解時會放熱，要等溶液冷卻到室溫。
3. 把溶液倒進250毫升的容量瓶，用少量水沖洗燒杯，洗液也倒進容量瓶，溶質才不會留在燒杯裡。
4. 加水到接近刻度，再慢慢滴加，讓液面最低處對齊刻度線，蓋上瓶塞，倒轉幾次混合均勻。

**稀釋**　在溶液裡加水，會發生什麼事？先猜一題。

<Predict id="sol-dilution" prompt="取2.0 M的鹽酸50毫升，加水稀釋成500毫升的溶液。稀釋後的濃度是多少M？" answer={0.2} unit="M">

加水只加了溶劑，**溶質的莫耳數不變**。稀釋前 $n=2.0\times0.050=0.10$ 莫耳，稀釋後仍是0.10莫耳，分到0.500公升中：$0.10\div0.500=0.20\ \mathrm{M}$。體積變成10倍，濃度就變成 $\frac{1}{10}$。

</Predict>

把「溶質莫耳數不變」寫成式子：

$$
C_1V_1=C_2V_2
$$

兩邊的體積只要用同一種單位（都用毫升或都用公升）就可以。

<StudentAsks q="用C₁V₁＝C₂V₂算出的V₂，就是要加的水量嗎？">

不是。$V_2$ 是稀釋**後溶液的總體積**。上面的例子中 $V_2=500$ 毫升，原本已有50毫升溶液，所以加水後的總體積要到500毫升（若體積可以直接相加，大約加450毫升的水）。題目問「加多少水」時，要再減一次。

</StudentAsks>

</Perspective>

把100毫升、1.0 M的食鹽水和300毫升、0.20 M的食鹽水混合，假設體積可以直接相加。混合後的濃度是多少？先算出答案，再往下讀。

</TryIt>

答案：溶質共 $1.0\times0.100+0.20\times0.300=0.10+0.060=0.16$ 莫耳，總體積0.400公升，濃度是 $0.16\div0.400=0.40\ \mathrm{M}$。注意它不是兩個濃度的平均0.60 M：300毫升的那一杯比較多，結果比較靠近0.20 M。

## 溶解度與溫度

在定溫下，一定量的溶劑最多能溶解的溶質量，叫做<Term t="chemistry.solubility">溶解度</Term>，常用「每100公克水最多溶解幾公克溶質」表示。溶到這個量、不能再溶的溶液叫<Term t="chemistry.saturated-solution">飽和溶液</Term>，還能再溶的叫未飽和溶液。

大多數固體的溶解度隨溫度升高而增加，增加的程度因物質而異：硝酸鉀增加很多，氯化鈉幾乎不變。把溶解度對溫度畫圖，就是**溶解度曲線**。下圖用兩種假想的物質甲、乙來練習讀圖。

拉動 $T$，讀出甲在20℃和60℃的溶解度；再找兩條線大約在幾℃相交。讀完再往下看。

<Predict id="sol-crystals" prompt="100公克的水在60℃溶入甲到恰好飽和，再冷卻到20℃（水量不變）。會析出幾公克甲的晶體？" answer={64} unit="公克">

60℃時100公克水溶了82公克甲；冷卻到20℃，同樣的水最多只能溶18公克。溶不下的 $82-18=64$ 公克就結晶析出。溫度降低、溶解度變小，多出來的溶質變回固體，這就是課綱「溶解度曲線與結晶」實驗的原理。如果水是50公克，所有的量都減半，析出32公克。

</Predict>

<StudentAsks q="溶解度一定隨溫度升高而變大嗎？">

不一定。大多數固體是如此，但**氣體相反**：溫度越高，氣體在水中的溶解度越小。所以汽水放到不冰了，冒出的氣泡比冰的時候多。讀題時要看清楚是哪一種溶質的曲線，不要套用同一個印象。

</StudentAsks>

<Perspective title="溶解度曲線是怎麼量出來的">

曲線上的每一點，都是一個「剛好飽和」的狀態。課綱的實驗可以這樣做：

1. 在試管中放10公克水和已知質量的甲，加熱攪拌到完全溶解。
2. 慢慢冷卻並攪拌，記下**晶體剛出現**時的溫度。這一刻溶液剛好飽和。
3. 換不同質量的甲重做，每一次得到曲線上的一個點。

**例**　10公克水加2.8公克甲，晶體在30℃出現；10公克水加6.0公克甲，晶體在50℃出現。換算成每100公克水，就是（30℃，28公克）和（50℃，60公克）兩個點。把幾個這樣的點連起來，就是上圖的曲線甲。115學測第25至27題從香蕉萃取鉀鹽的探究題組，也用到溶解度。

</Perspective>

## 飽和溶液：溶解與結晶的平衡

把過量的甲放進定溫的水中攪拌。一開始溶解很快；溶液中的溶質粒子越來越多，碰回固體表面、重新結晶的機會也越來越多。當結晶的速率追上溶解的速率，兩者相等，溶液的濃度就不再改變：這就是飽和溶液。

<Graph desc="橫軸是時間（任意單位），縱軸是速率（相對大小）。藍色水平線是溶解速率，固定為1。紅色曲線是結晶速率，從0開始上升，越來越接近1。拉動t，兩個點和連接它們的虛線顯示兩種速率的差距：一開始差距很大，後來越來越小，最後兩者幾乎相等，但都不是零。" x={[0, 6]} y={[0, 1.4]} height={280} equal={false}
  params={[{ name: 't', min: 0, max: 6, step: 0.25, value: 0.5, label: '時間t' }]}
  functions={[{ expr: '1', color: 'blue' }, { expr: '1-exp(-x)', color: 'red' }]}
  points={[{ at: ['t', 1], color: 'blue' }, { at: ['t', '1-exp(-t)'], color: 'red' }]}
  segments={[{ from: ['t', '1-exp(-t)'], to: ['t', 1], dashed: true }]}
  labels={[{ at: [4.5, 1.15], text: '溶解', color: 'blue' }, { at: [1.6, 0.4], text: '結晶', color: 'red' }]} />

把 $t$ 從0往右拉，看虛線（溶解比結晶快多少）怎麼變：它越來越短，最後兩條線幾乎重合。重合時，溶解和結晶**都沒有停**，只是一樣快，所以固體和溶液的量都不再改變。這種狀態叫<Term t="chemistry.equilibrium-state">平衡狀態</Term>，這裡就是溶解平衡。國中學過的可逆反應與化學平衡也是同一個意思：看起來不變，其實兩個方向一直在進行。

有了這個想法，溶解度曲線也可以當成「狀態地圖」來讀。例如40℃時，100公克水中溶有30公克甲：曲線上40℃是42公克，30在曲線下方，溶液**未飽和**，還能再溶12公克。點落在曲線上是飽和；點若在曲線上方，溶不下的部分通常會析出。

<Perspective title="證據：晶體的形狀變了，質量卻沒變">

怎麼知道飽和溶液裡溶解和結晶還在進行？可以做這個實驗：

1. 把一塊形狀不規則的甲晶體，放進同溫度的甲飽和溶液中，蓋好避免水分蒸發，保持溫度不變。
2. 放幾天後取出：晶體的**形狀變了**，有的角溶掉了，有的地方長出新的晶面。
3. 擦乾秤重，**質量幾乎沒變**，溶液的濃度也沒變。

如果溶解已經停止，晶體的形狀不會改變；如果只有溶解，晶體會變輕。「形狀改變而質量不變」只有一種解釋：溶解和結晶同時進行，而且速率相等。這正是上圖兩條速率線重合時的樣子。

</Perspective>

<Perspective later title="下一章的［H⁺］也是體積莫耳濃度" needs="酸鹼反應（下一章）" href="/zh-tw/chemistry/s116-acids-bases/">

下一章會用 $[\ce{H+}]$ 表示水溶液中氫離子的濃度，它的單位就是本章的 $\mathrm{M}$。例如0.010 M的鹽酸中，每個 $\ce{HCl}$ 在水中解離出一個 $\ce{H+}$，所以 $[\ce{H+}]=0.010\ \mathrm{M}$。pH就是由 $[\ce{H+}]$ 算出來的；稀釋一杯酸，$[\ce{H+}]$ 也照本章的 $C_1V_1=C_2V_2$ 變小。

</Perspective>
