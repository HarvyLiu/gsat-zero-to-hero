這是116衝刺的重點複習：假設你在學校讀過必修化學，也記得國中「得氧、失氧」的說法。課綱對這個單元的要求是：用電子的得失說明氧化還原，並認識常見的氧化劑（氧氣、臭氧、雙氧水、次氯酸、氯氣）、還原劑（焦煤、二氧化硫）與抗氧化劑（維生素C）。課綱說明寫明必修**不涉及氧化數的計算，也不涉及氧化還原反應的平衡**；最後一節的配平是學測考過的延伸，會清楚標出來。

## 從得失氧到得失電子

先看鎂燃燒：

$$
\ce{2Mg + O2 -> 2MgO}
$$

在化學鍵那一章看過，氧化鎂是<Term t="chemistry.ionic-compound">離子化合物</Term>，由 $\ce{Mg^2+}$ 和 $\ce{O^2-}$ 組成。鎂原子有2個<Term t="chemistry.valence-electron">價電子</Term>，氧原子有6個。反應時，電子從鎂跑到氧。

<TryIt>

把p從0慢慢拉到1。電子到達以後數一數：氧的外圈有幾個電子？鎂的外圈還剩幾個？先數完再往下讀。

</TryIt>

氧的外圈變成8個，鎂的2個價電子全交了出去。國中說「鎂得到氧」，用電子的眼光看，其實是「鎂失去電子、氧得到電子」。高中的定義就是：

- **<Term t="chemistry.oxidation">氧化</Term>：失去電子。**鎂失去電子，被氧化：$\ce{Mg -> Mg^2+ + 2e-}$。
- **<Term t="chemistry.reduction">還原</Term>：得到電子。**氧得到電子，被還原。

這樣一來，開頭的鈉和氯氣也說得通：$\ce{2Na + Cl2 -> 2NaCl}$ 中，每個鈉原子失去1個電子成為 $\ce{Na+}$，被氧化；每個氯原子得到1個電子成為 $\ce{Cl-}$，被還原。沒有氧，照樣是氧化還原反應。

<Perspective title="兩種定義放在一起比">

國中做過「氧化銅和碳粉混合加熱，得到紅色的銅」：$\ce{2CuO + C -> 2Cu + CO2}$。氧化銅不帶電，氧以 $\ce{O^2-}$ 存在，所以銅的電荷 $x$ 滿足 $x+(-2)=0$，$x=+2$，銅以 $\ce{Cu^2+}$ 存在。

| 反應 | 有氧參加嗎 | 國中：得失氧 | 高中：得失電子 |
|---|---|---|---|
| $\ce{2Mg + O2 -> 2MgO}$ | 有 | 鎂得到氧，被氧化 | 每個鎂失去2個電子，被氧化；每個氧得到2個，被還原 |
| $\ce{2CuO + C -> 2Cu + CO2}$ | 有 | 氧化銅失去氧，被還原；碳得到氧，被氧化 | 每個 $\ce{Cu^2+}$ 得到2個電子變成銅，被還原 |
| $\ce{2Na + Cl2 -> 2NaCl}$ | 沒有 | 說不出來 | 每個鈉失去1個電子，被氧化；每個氯得到1個，被還原 |

有氧的時候，兩種定義的結論一致；沒有氧的時候，只有電子的定義能用。所以國中的說法是高中定義的特例。表中碳變成 $\ce{CO2}$ 分子而不是離子，它的電子怎麼算要用到氧化數，必修不談，這裡就用得氧的說法。

</Perspective>

<StudentAsks q="沒有氧也叫「氧化」，這個名字不會很奇怪嗎？">

「氧化」原本就是指和氧結合，名字是從那時沿用下來的。後來發現，和氧結合時真正發生的是電子的轉移，而別的反應也有同樣的電子轉移，定義就擴大了，名字沒有改。記的時候別看字面，看電子：失去是氧化，得到是還原。

</StudentAsks>

## 氧化與還原一定同時發生

國中也做過：鋅片放進藍色的硫酸銅溶液，鋅片表面出現紅棕色的銅，溶液的藍色漸漸變淡。硫酸根離子 $\ce{SO4^2-}$ 反應前後都一樣，沒有參與電子轉移，所以反應式裡省略它：

$$
\ce{Zn + Cu^2+ -> Zn^2+ + Cu}
$$

讀縱軸：電子帶負電，粒子失去電子，電荷就變得比較正，箭頭朝上；得到電子，箭頭朝下。鋅的箭頭往上2格，每個鋅原子失去2個電子；銅的箭頭往下2格，每個 $\ce{Cu^2+}$ 得到2個電子。

兩支箭頭一樣長不是巧合：鋅失去的2個電子，正是 $\ce{Cu^2+}$ 得到的那2個。電子不會憑空消失，有人失去就一定有人得到。所以**氧化和還原一定同時發生**，而且**失去的電子數等於得到的電子數**。這就是為什麼合起來叫「氧化還原反應」。

<StudentAsks q="非選擇題問「這是什麼反應」，可以只寫「氧化反應」嗎？">

不行。111學測第57題公布的評分原則中，只寫「氧化反應」或只寫「還原反應」都只得一半分數，要寫「氧化還原反應」才完整。原因就是這一節：有人失去電子，就一定有人得到，兩者不會單獨發生。

</StudentAsks>

## 氧化劑與還原劑

在反應中讓別的物質被氧化的物質，叫做<Term t="chemistry.oxidizing-agent">氧化劑</Term>：它把對方的電子拿走，自己得到電子，所以**氧化劑本身被還原**。讓別的物質被還原的物質，叫做<Term t="chemistry.reducing-agent">還原劑</Term>：它把電子交給對方，所以**還原劑本身被氧化**。例如鎂燃燒時，氧氣拿走鎂的電子，是氧化劑；鎂是還原劑。

```dialogue
S：氧化劑、被氧化……名字好像，我一定會搞混。
T：那就馬上練一題。鐵釘放進硫酸銅溶液，表面也會析出銅：$\ce{Fe + Cu^2+ -> Fe^2+ + Cu}$。哪一個是氧化劑？
>> turn: q-mid
S：是 $\ce{Cu^2+}$。它得到電子，自己被還原；它讓鐵失去電子，所以叫氧化劑。
T：對。名字說的是它「對別人做了什麼」，不是它自己發生了什麼。
```

<Perspective title="用得失氧來找氧化劑與還原劑">

國中也有「氧化劑、還原劑」的說法，那時是看氧的去向。回到 $\ce{2CuO + C -> 2Cu + CO2}$：

1. 碳從氧化銅那裡**拿走氧**，讓氧化銅被還原，所以碳是還原劑；碳自己得到氧，被氧化。
2. 氧化銅把氧**交出去**，讓碳被氧化，所以氧化銅是氧化劑；它自己失去氧，被還原。

用電子檢查氧化銅：$\ce{Cu^2+}$ 得到2個電子變成銅，得到電子的是氧化劑，結論相同。兩種看法在有氧的反應裡一致；遇到沒有氧的反應，例如鐵和 $\ce{Cu^2+}$，就只能看電子。

</Perspective>

<StudentAsks q="氧化劑一定含有氧嗎？">

不一定。氯氣 $\ce{Cl2}$ 一個氧原子也沒有，卻是課綱列出的常見氧化劑；反過來，二氧化硫 $\ce{SO2}$ 含有氧，卻是常見的還原劑。名字裡的「氧化」說的是「讓別人失去電子」，不是「含有氧」。判斷時只看它在反應中得到電子還是失去電子。

</StudentAsks>

## 生活中的氧化劑、還原劑與抗氧化劑

課綱指定要認識的物質如下：

| 物質 | 角色 | 生活中的例子 |
|---|---|---|
| 氧氣 $\ce{O2}$ | 氧化劑 | 燃燒、鐵生鏽 |
| 臭氧 $\ce{O3}$ | 氧化劑 | 殺菌、消毒 |
| 雙氧水（過氧化氫 $\ce{H2O2}$ 的水溶液） | 氧化劑 | 傷口消毒 |
| 次氯酸 $\ce{HOCl}$ | 氧化劑 | 氯氣溶在水中會生成次氯酸，用來消毒 |
| 氯氣 $\ce{Cl2}$ | 氧化劑 | 自來水加氯消毒 |
| 焦煤（主要成分是碳） | 還原劑 | 煉鐵：把鐵礦中的氧化鐵還原成鐵 |
| 二氧化硫 $\ce{SO2}$ | 還原劑 | —（本章不舉例） |
| 維生素C | 抗氧化劑（扮演還原劑） | 加在食品、果汁中，減少其他成分被氧化 |

二氧化硫是課綱列出的常見還原劑，本章不介紹它的用途。

看焦煤煉鐵。用國中的說法：碳拿走氧化鐵 $\ce{Fe2O3}$ 的氧，氧化鐵被還原成鐵。用電子的說法，要先知道鐵離子帶多少電荷。

化合物不帶電，正負電荷加起來是零：$2x+3\times(-2)=0$，$x=+3$。所以氧化鐵中的鐵是 $\ce{Fe^3+}$。

</Predict>

<Perspective title="抗氧化劑：搶先被氧化的還原劑">

「抗氧化」聽起來像在對抗氧化劑，用電子帳看就清楚了：

1. 空氣中的氧氣是氧化劑，要從別的物質拿電子。
2. 果汁裡的許多成分都可能把電子交給氧，也就是被氧化，品質因此變差。
3. 維生素C很容易失去電子。氧先從它那裡拿，維生素C被氧化；它還沒用完以前，其他成分就比較少被氧化。

所以抗氧化劑本身就是一種還原劑：它保護別人的方法，是**自己先被氧化**。它被氧化掉之後就失去作用，這也是它會「用完」的原因。

</Perspective>

## 延伸（學測考過）：用原子和電荷配平

課綱說明寫明必修不涉及氧化還原反應的平衡，但111學測第57題要求寫出一個含離子的氧化還原反應式的完整係數；評分原則寫明全部係數都對才得滿分，係數寫成分數或整組加倍只得部分分數。用的工具其實就是[化學反應式與化學計量](/zh-tw/chemistry/s116-equations-stoichiometry/)那一章的代數法，再多加一條：**電荷也要守恆**。

看鋁和銅離子的反應（尚未平衡）：

$$
\ce{Al + Cu^2+ -> Al^3+ + Cu}
$$

原子已經各1個，但左邊總電荷 $+2$、右邊 $+3$，不平衡。

<Predict id="rx-al-cu" prompt="把Al + Cu²⁺ → Al³⁺ + Cu配平成最簡整數係數，Cu²⁺的係數是多少？" answer={3}>

每個鋁失去3個電子，每個 $\ce{Cu^2+}$ 得到2個電子。失去和得到要相等，取3和2的最小公倍數6：2個鋁失去6個，3個 $\ce{Cu^2+}$ 得到6個。所以配平後是

$$
\ce{2Al + 3Cu^2+ -> 2Al^3+ + 3Cu}
$$

$\ce{Cu^2+}$ 的係數是3。檢查電荷：左邊 $3\times(+2)=+6$，右邊 $2\times(+3)=+6$，相等。

</Predict>

用電子帳的長條再配平一個反應（尚未平衡）：

$$
\ce{Zn + Fe^3+ -> Zn^2+ + Fe}
$$

每個鋅原子失去2個電子，每個 $\ce{Fe^3+}$ 得到3個電子。

先讓a=1，找一個b讓兩根長條等高，找得到嗎？再試a=2、a=3。接著找出另一組也能等高的a、b，想想它為什麼不算「最簡整數係數」。

a=1、2時，左邊是2、4，右邊只能是3、6、9……都對不上；a=3、b=2時兩根都是6，所以

$$
\ce{3Zn + 2Fe^3+ -> 3Zn^2+ + 2Fe}
$$

檢查電荷：左邊 $2\times(+3)=+6$，右邊 $3\times(+2)=+6$。a=6、b=4也等高，但那是整組加倍，評分原則說加倍的係數只得部分分數。

<Perspective title="代數法：原子一條式子、電荷一條式子">

不想數電子，也可以直接解方程式。設 $a\,\ce{Al} + b\,\ce{Cu^2+} \longrightarrow c\,\ce{Al^3+} + d\,\ce{Cu}$：

1. 鋁原子守恆：$a=c$。
2. 銅原子守恆：$b=d$。
3. 電荷守恆：左邊 $2b$，右邊 $3c$，所以 $2b=3c$。
4. 取 $c=2$，得 $a=2$、$b=3$、$d=3$。

和電子帳的答案一樣。兩種方法其實是同一件事：電荷守恆的那條式子，正是「失去的電子數等於得到的電子數」換個寫法。

</Perspective>

<Perspective later title="氧化數：連分子也能數電子" needs="選修化學（氧化數與半反應法，不考學測）">

這一章只在離子身上數電子，因為離子的電荷直接告訴你它失去或得到幾個電子。像 $\ce{2CuO + C -> 2Cu + CO2}$ 中的碳，最後在 $\ce{CO2}$ 分子裡，並沒有變成離子，電子只是偏向氧，沒有整個交出去。選修化學用「氧化數」把這種情形也記成假想的電荷，於是任何反應都能記電子帳，並發展出配平複雜氧化還原反應式的方法。學測的必修範圍不需要它。

</Perspective>
