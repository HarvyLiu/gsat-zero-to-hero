選擇題也有規則要知道。多選題的計分方式是：<Fact id="exam.multi-select-scoring" />

<Perspective title="把多選題的計分算一遍">

以一題 $2$ 分、$5$ 個選項的多選題為例，$n=5$，答錯 $k$ 個選項得 $2\times\dfrac{5-2k}{5}$ 分。每個選項都要判定：該選的沒選、不該選的選了，都算答錯一個。

| 答錯的選項數 $k$ | $0$ | $1$ | $2$ | $3$ 以上 |
|---|---|---|---|---|
| $\dfrac{5-2k}{5}$ | $1$ | $\frac{3}{5}$ | $\frac{1}{5}$ | 負數 |
| 得分 | $2$ | $1.2$ | $0.4$ | $0$ |

每多錯一個選項就少 $0.8$ 分；錯到 $3$ 個，$5-2k$ 變成負數，以零分計。所以多選題的每一個選項，都要像一道小是非題一樣，回到題幹找根據再判定。

</Perspective>

## 從圖表與題幹找線索

探究題組常常先描述一個實驗，再給表格或圖，最後一連問好幾題。讀的順序可以是：

1. **先看問題問什麼**，再回頭找需要的數據。
2. **圈出數字的單位與基準**，例如「每100公克水」。
3. **題幹給的定義與條件優先**，即使課本沒教過也照著用。
4. **讀圖先看兩軸**是什麼量、什麼單位，再看圖例分辨每條線。

**例題（自編的探究題組）**　某同學想知道溫度對甲、乙兩種固體在水中<Term t="chemistry.solubility">溶解度</Term>的影響。每次取100公克水，在不同溫度下加入固體並攪拌，直到不再溶解，記錄溶解的質量。題幹另外說明：先在高溫把固體溶成飽和溶液，冷卻後讓晶體析出，可以用來純化固體。（甲、乙是假想的物質，數據為練習而編。）

| 溫度（℃） | $20$ | $40$ | $60$ | $80$ |
|---|---|---|---|---|
| 甲（公克／100公克水） | $24$ | $36$ | $56$ | $84$ |
| 乙（公克／100公克水） | $36$ | $37$ | $38$ | $39$ |

<Predict id="cw-crystals" prompt="200公克水在80℃溶成甲的飽和溶液，冷卻到20℃（水量不變），會析出多少公克甲？" answer={120} unit="公克">

表上的數字是「每100公克水」，200公克水是它的2倍。80℃時最多溶 $2\times84=168$ 公克甲，冷卻到20℃時只能溶 $2\times24=48$ 公克，多出的 $168-48=120$ 公克析出成晶體。也可以先算每100公克水析出 $84-24=60$ 公克，再乘以2。忘了基準，就會答成60。

</Predict>

在甲的曲線上找縱座標56的點：60℃。冷卻到60℃時溶液剛好飽和，再冷下去就會析出晶體。

再用圖回答「哪一種適合用這個方法純化」：甲從80℃冷卻到20℃，每100公克水析出60公克；乙只析出 $39-36=3$ 公克。溶解度隨溫度變化大的甲適合，乙不適合。這個方法叫做<Term t="chemistry.recrystallization">再結晶</Term>，必修化學不談，但112、114學測的選項都出現過。這一題的題幹已經說明了做法，照著題幹推理就能作答。

## 計算題：讓閱卷者看得到每一步

**例題**　甲烷完全燃燒：$\ce{CH4 + 2O2 -> CO2 + 2H2O}$。燃燒3.2公克甲烷，生成多少公克二氧化碳？（原子量：H＝1，C＝12，O＝16）

<Predict id="cw-co2" prompt="燃燒3.2公克甲烷，生成多少公克二氧化碳？" answer={8.8} unit="公克">

完整的寫法分四步，每一步都寫出數字的來源和單位：

1. 反應式（已平衡）：$\ce{CH4 + 2O2 -> CO2 + 2H2O}$。
2. 甲烷的<Term t="chemistry.molar-mass">莫耳質量</Term>是 $12+4\times1=16\ \mathrm{g/mol}$，$n_{\ce{CH4}}=\dfrac{3.2\ \mathrm{g}}{16\ \mathrm{g/mol}}=0.20\ \mathrm{mol}$。
3. 係數比 $\ce{CH4}:\ce{CO2}=1:1$，所以 $n_{\ce{CO2}}=0.20\ \mathrm{mol}$。
4. $\ce{CO2}$ 的莫耳質量是 $12+2\times16=44\ \mathrm{g/mol}$，質量 $=0.20\ \mathrm{mol}\times44\ \mathrm{g/mol}=8.8\ \mathrm{g}$。

</Predict>

比較另外兩種寫法：只寫「8.8公克」，閱卷者看不到任何推理；寫「$3.2\div16\times44=8.8$」，16和44從哪裡來、為什麼可以直接相乘，都沒有交代。四步的寫法把<Term t="chemistry.stoichiometry">化學計量</Term>的鏈條「質量 → 莫耳數 → 係數比 → 質量」完整攤開，而且每一步都能自己驗算。

<Perspective title="用質量比看：畫一條直線">

不換算莫耳數也能算。反應式說 $1$ 莫耳甲烷生成 $1$ 莫耳二氧化碳，也就是16公克甲烷生成44公克二氧化碳。燃燒的甲烷越多，生成的二氧化碳按比例增加，兩者的關係是一條通過原點的直線，斜率是 $\dfrac{44}{16}=2.75$。

把 $m$ 拉到3.2，讀出縱座標。你會讀到8.8，和莫耳法一樣；用比例式寫就是 $16:44=3.2:x$，$x=8.8$。兩種方法其實是同一件事：莫耳法把「16公克對44公克」拆成「每莫耳的質量」和「係數比」兩步。係數比不是 $1:1$ 時，比例式要寫成「係數×莫耳質量」的比，這時莫耳法比較不容易出錯。

</Perspective>

<StudentAsks q="最後一步算錯了，前面寫的算式還有分數嗎？">

沒有通則，要看各題的評分原則。111學測化學的兩題非選擇題就不一樣：第38題（2分）只有全對或零分；第57題則對某些不完整的答案給一半的分數。評分原則的說明只要求你把解題過程清楚寫出。所以不要指望「寫了算式就有分」；把過程寫清楚，真正的好處是你能沿著每一步檢查，在交卷前抓到自己的錯。

## 說明理由：條件、規則、結論

問「為什麼」或「說明理由」的題目，答案寫成三段：

1. **條件**：題目給了什麼、發生了什麼變化。
2. **規則**：用哪一條化學規則，以及它在這裡怎麼作用。
3. **結論**：回答題目問的東西，數值、單位或方向都寫清楚。

**例題**　本章的酸鹼計算都以25℃為準。pH＝11的氫氧化鈉溶液，加水稀釋成原來體積的100倍，pH變成多少？說明理由。

1. **條件**：pH＝11，所以 $[\ce{H+}]=10^{-11}\ \mathrm{M}$；25℃時 $[\ce{OH-}]=\dfrac{1.00\times10^{-14}}{10^{-11}}=10^{-3}\ \mathrm{M}$。稀釋時 $\ce{OH-}$ 的莫耳數不變，體積變成100倍。
2. **規則**：濃度＝莫耳數÷體積，所以 $[\ce{OH-}]$ 變成 $10^{-3}\div100=10^{-5}\ \mathrm{M}$；再由 $[\ce{H+}][\ce{OH-}]=1.00\times10^{-14}$，得 $[\ce{H+}]=10^{-9}\ \mathrm{M}$。
3. **結論**：稀釋後pH＝9，仍是鹼性。

從數線讀出：pH移動了幾格？是往7靠近還是遠離7？稀釋100倍是 $10^2$，所以移動2格，而且往中性靠近。這和[酸鹼反應](/zh-tw/chemistry/s116-acids-bases/)那一章用<Term t="math.common-logarithm">常用對數</Term>算出的規律一致。

結論也要寫完整。111學測第57題有一小題，只寫「氧化反應」或只寫「還原反應」都只得一半分數；氧化和還原一定同時發生，完整的寫法是「氧化還原反應」。

<TryIt>

有同學這樣寫：「pH變成9，因為稀釋了。」對照三段式，他少了哪一段？先寫下你的答案再往下讀。

</TryIt>

他有條件（稀釋了）和結論（pH＝9），少了**規則**：$\ce{OH-}$ 的莫耳數不變、濃度變成百分之一，以及用 $[\ce{H+}][\ce{OH-}]=1.00\times10^{-14}$ 換回 $[\ce{H+}]$。少了中間這段，閱卷者看不出9是怎麼來的。

## 反應式：最簡整數係數

題目要你寫反應式時，寫完逐項檢查：

1. 每個化學式都正確。
2. 每種原子左右一樣多。
3. 有離子時，左右的總電荷也一樣。
4. 係數都是整數，而且沒有共同因數。

**例題**　丙烷 $\ce{C3H8}$ 完全燃燒生成二氧化碳和水。先令丙烷的係數為1：C有3個，所以是 $3\ce{CO2}$；H有8個，所以是 $4\ce{H2O}$。右邊的O共有 $3\times2+4=10$ 個，左邊每個 $\ce{O2}$ 有2個O。

<Graph desc="示意圖，比較氧原子數。左邊長條的高度是2b，表示b個O₂分子中的氧原子數；虛線標出右邊3CO₂＋4H₂O共有的10個氧原子。拉動b（O₂的係數，1到8）：左邊長條剛好碰到虛線時，兩邊的氧原子一樣多。" x={[0, 4.4]} y={[-1.8, 17.5]} height={280} equal={false} axes={false}
  params={[{ name: 'b', label: 'O₂的係數b', min: 1, max: 8, step: 1, value: 1 }]}
  polygons={[{ points: [[0.6, 0], [1.6, 0], [1.6, '2*b'], [0.6, '2*b']], color: 'blue' }, { points: [[2.6, 0], [3.6, 0], [3.6, 10], [2.6, 10]], color: 'amber' }]}
  segments={[{ from: [0.3, 10], to: [3.9, 10], dashed: true }]}
  labels={[{ at: [0.6, -1.3], text: '左邊O' }, { at: [2.6, -1.3], text: '右邊O' }, { at: [2.7, 11], text: '10個' }]} />

拉動 $b$，讓左邊的長條剛好碰到虛線。$b$ 是多少？先在圖上找到再往下讀。

$b=5$ 時兩邊都是10個O，所以

$$
\ce{C3H8 + 5O2 -> 3CO2 + 4H2O}
$$

注意兩個陷阱。加倍的式子

$$
\ce{2C3H8 + 10O2 -> 6CO2 + 8H2O}
$$

原子也守恆，但係數都能除以2，不是最簡；若令1以後出現分數，例如乙炔 $\ce{C2H2}$ 燃燒需要 $\frac{5}{2}\ce{O2}$，就全部乘以2，寫成

$$
\ce{2C2H2 + 5O2 -> 4CO2 + 2H2O}
$$

<Perspective title="代數法：每種原子一條方程式">

不想一個一個試，就用[化學反應式與化學計量](/zh-tw/chemistry/s116-equations-stoichiometry/)那一章的代數法。設 $a\,\ce{C3H8} + b\,\ce{O2} \longrightarrow c\,\ce{CO2} + d\,\ce{H2O}$：

1. C守恆：$3a=c$。
2. H守恆：$8a=2d$。
3. O守恆：$2b=2c+d$。
4. 令 $a=1$，得 $c=3$、$d=4$、$2b=6+4$，$b=5$。

和長條圖的答案一樣。代數法的好處是步驟固定：解出來若有分數，就乘上分母的最小公倍數；若係數有共同因數，就全部除掉。這兩步做完，係數一定是最簡整數。

</Perspective>

<StudentAsks q="熱化學反應式不是可以寫分數係數嗎？">

可以。[化學反應中的能量變化](/zh-tw/chemistry/s116-reaction-energy/)那一章說過，<Term t="chemistry.thermochemical-equation">熱化學反應式</Term>的係數代表莫耳數，常常為了讓某個物質剛好是1莫耳而寫成分數。但題目若要求「最簡整數係數」，就要照題目寫成整數；111學測第57題的評分原則就對分數係數只給部分分數。所以先看清楚題目要的是哪一種寫法。

</StudentAsks>

<Perspective title="延伸（學測考過）：離子反應式還要電荷守恆">

課綱說明寫明必修不涉及氧化還原反應的平衡，但111學測第57題要求寫出一個含離子的氧化還原反應式的完整係數，評分原則要全部係數都對才得滿分。[氧化還原反應](/zh-tw/chemistry/s116-redox/)那一章用過的方法就夠了：原子守恆再加上電荷守恆。

看一個自編的例子（尚未平衡）：

$$
\ce{MnO4- + Fe^2+ + H+ -> Mn^2+ + Fe^3+ + H2O}
$$

設係數依序為 $a,b,c,d,e,f$，令 $a=1$：

1. Mn守恆：$d=1$；O守恆：$f=4$；H守恆：$c=2f=8$；鐵守恆：$e=b$。
2. 只剩 $b$ 要由電荷決定：左邊總電荷 $-1+2b+8=2b+7$，右邊 $2+3b$。

<Graph desc="示意圖，比較兩邊的總電荷。左邊長條的高度是2b＋7，右邊長條的高度是3b＋2，b是亞鐵離子和鐵離子的係數。拉動b（1到8）：b小時左邊較高，b大時右邊較高，b＝5時兩根長條同高，都是17。" x={[0, 4.4]} y={[-2.5, 27]} height={280} equal={false} axes={false}
  params={[{ name: 'b', label: '鐵的係數b', min: 1, max: 8, step: 1, value: 1 }]}
  polygons={[{ points: [[0.6, 0], [1.6, 0], [1.6, '2*b+7'], [0.6, '2*b+7']], color: 'blue' }, { points: [[2.6, 0], [3.6, 0], [3.6, '3*b+2'], [2.6, '3*b+2']], color: 'amber' }]}
  labels={[{ at: [0.4, -1.8], text: '左邊電荷' }, { at: [2.4, -1.8], text: '右邊電荷' }]} />

拉動 $b$ 讓兩根長條同高：$b=5$，兩邊都是 $+17$。所以

$$
\ce{MnO4- + 5Fe^2+ + 8H+ -> Mn^2+ + 5Fe^3+ + 4H2O}
$$

用代數解也一樣：$2b+7=3b+2$，$b=5$。最後檢查：係數 $1,5,8,1,5,4$ 沒有共同因數，是最簡整數。

</Perspective>
