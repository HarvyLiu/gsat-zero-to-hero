## 選填題：照著格子劃

選填題不是寫算式，而是把答案一格一格劃記在答案卡上。題目會用 ①②③… 標出每一格，告訴你答案長什麼樣子，例如 $\dfrac{①②}{③}$、$①\sqrt{②}$ 或 $①.②③$。每一格只劃一個符號：$0$～$9$ 其中一個數字，或負號 $-$。

選填題要每一格都對才給分，答錯不倒扣；負號也要劃記（大考中心的計分規則，本站「學測資訊」頁附有出處）。所以：

- **負號佔一格。** 答案是負數時，負號要劃在題目留給它的那一格。
- **整數部分是 $0$ 也要劃。** $①.②$ 的答案若是 $0.5$，① 要劃 $0$，不能空著。
- **化到題目要的形式。** 題目說「最簡分數」，就要約分；格式是 $①\sqrt{②}$，根號裡就不能再有平方因數。
- **不會也要劃。** 答錯不倒扣，空著一定沒分。

**例題**　$\dfrac{1}{4}-1$ 的答案格式是 $\dfrac{①②}{③}$，怎麼劃記？

$\frac{1}{4}-1=-\frac{3}{4}$。分子 $-3$ 有兩個符號，剛好填 ①②：① 劃 $-$、② 劃 $3$；分母 ③ 劃 $4$。

**例題**　$\sqrt{12}$ 的答案格式是 $①\sqrt{②}$，怎麼劃記？

$\sqrt{12}=\sqrt{4\times 3}=2\sqrt{3}$，所以 ① 劃 $2$、② 劃 $3$。如果直接寫成 $1\sqrt{12}$，② 需要兩格，格子數對不上，這就是在提醒你還沒化簡。

<Perspective title="用面積看：為什麼 √12 = 2√3">

$\sqrt{12}$ 是面積 $12$ 的正方形的邊長。因為 $12=4\times 3$，可以把這個正方形切成 $2\times 2$ 個小正方形，每個面積 $3$、邊長 $\sqrt{3}$。大正方形的一邊排了 $2$ 個小正方形，所以邊長是 $2\sqrt{3}$。

根號外面的係數，就是一邊排了幾個小正方形；根號裡面剩下的，是小正方形的面積。化到最簡，就是小正方形的面積不能再拆成 $m\times m$ 個（$m\ge 2$）面積是整數的更小正方形，也就是根號裡沒有平方因數。例如 $\sqrt{18}$：$18=9\times 2$，切成 $3\times 3$ 個面積 $2$ 的小正方形，邊長是 $3\sqrt{2}$，格式 $①\sqrt{②}$ 就劃 $3$、$2$。

</Perspective>

<StudentAsks q="格子數對得上，就代表我算對了嗎？">

不一定。格子數只能幫你抓出一部分錯誤。例如題目要求最簡分數、格式是 $\dfrac{①}{②}$，你算出 $\frac{6}{8}$ 也塞得進去，可是沒有約分成 $\frac{3}{4}$，劃 $6$、$8$ 這題就沒分。格子對不上時一定要回頭檢查；格子對得上時，也要確認是不是題目要的最後形式。

</StudentAsks>

## 多選題：每個選項分開判定

多選題的計分方式是：<Fact id="exam.multi-select-scoring" />

這裡的「答錯」是以**選項**為單位：一個選項只要「是答案卻沒劃」或「不是答案卻劃了」，就算判斷錯一個。以一題 $5$ 分、$5$ 個選項（$n=5$）為例，得分是 $\frac{5-2k}{5}\times 5=5-2k$ 分，算出負數就以 $0$ 分計：

| 判斷錯的選項數 $k$ | $0$ | $1$ | $2$ | $3$ 以上 |
|---|---|---|---|---|
| 得分 | $5$ | $3$ | $1$ | $0$ |

<Graph desc="橫軸是判斷錯的選項數 k，縱軸是一題 5 分、5 個選項時的得分。虛線是 y=5−2k，斜率 −2：每多錯一個就往下掉 2 分。k=0、1、2 的得分 5、3、1 落在虛線上；k=3、4、5 時虛線已經掉到 −1、−3、−5，但得分以 0 計，所以這三點畫在橫軸上。拉動滑桿 k（0 到 5 的整數），紅點標出這時的得分。" x={[-0.6, 5.6]} y={[-5.5, 5.8]}
  params={[{ name: 'k', label: '判斷錯的選項數 k', min: 0, max: 5, step: 1, value: 1 }]}
  functions={[{ expr: '5-2*x', domain: [0, 5], dashed: true, color: 'ink' }]}
  points={[{ at: [0, 5], color: 'ink' }, { at: [1, 3], color: 'ink' }, { at: [2, 1], color: 'ink' }, { at: [3, 0], color: 'ink' }, { at: [4, 0], color: 'ink' }, { at: [5, 0], color: 'ink' }, { at: ['k', '(5-2*k+abs(5-2*k))/2'], label: '得分', color: 'red' }]} />

從這條規則可以直接讀出三件事：

- **每判斷錯一個選項，扣 $2$ 分**，最低扣到 $0$ 分為止。劃錯和漏劃扣的一樣多。
- **不要空著。** 有作答的得分最低是 $0$ 分，和空著一樣，所以作答永遠不會比空著差。
- **正確選項「至少有一個」**，也可能只有一個。不要因為「多選題」三個字，就硬湊兩個以上。

每個選項只有「劃」和「不劃」兩種狀態，所以正確答案和你的劃記都可以寫成一排 $5$ 個開關。$k$ 就是兩排對不上的位置有幾個。以開場的題目為例：

<Graph desc="兩排各 5 個圓圈，對應選項 (1) 到 (5)。上排是正確答案 (1)(3)：第 1、3 個塗黑，其餘空心。下排是劃記 (1)(2)(3)：第 1、2、3 個塗黑。只有第 2 行上下不一樣，用橘色框起來，所以 k=1，得 5−2×1=3 分。" x={[-1.3, 5.7]} y={[0.2, 3.1]} height={200}

這樣看，計分只跟「哪些位置對不上」有關：多劃一個或漏劃一個，都是一個位置對不上，所以扣的一樣多。

也可以反過來數：正確答案固定時，恰好有 $k$ 個位置對不上的劃法，就是從 $5$ 個位置選 $k$ 個翻過來，有 $C^{5}_{k}$ 種。所以全部 $2^5=32$ 種劃法中，得 $5$ 分的有 $C^{5}_{0}=1$ 種、得 $3$ 分的有 $C^{5}_{1}=5$ 種、$k=2$ 的有 $C^{5}_{2}=10$ 種，其餘 $C^{5}_{3}+C^{5}_{4}+C^{5}_{5}=16$ 種都是 $0$ 分。只有一個例外：五個都不劃算空白，得 $0$ 分。正確答案是 (1)(3) 時，全部不劃剛好是 $k=2$ 的 $10$ 種之一，所以實際得 $1$ 分的只有 $9$ 種。後面「完全沒概念」那一段的 $\frac{1}{32}$、$\frac{5}{32}$、$\frac{10}{32}$，就是這些個數除以 $32$。

</Perspective>

### 沒把握的選項：用期望值決定

假設你對其中 $4$ 個選項的判斷都確定正確，只剩一個選項沒把握，你估計它是正確選項的機率是 $p$。不論劃不劃，這個選項不是判斷對（$k=0$，得 $5$ 分），就是判斷錯（$k=1$，得 $3$ 分），所以可以算<Term t="math.expected-value">期望值</Term>：

$$
\text{劃它：}\ 5p+3(1-p)=3+2p,\qquad \text{不劃：}\ 5(1-p)+3p=5-2p
$$

兩者相等時 $3+2p=5-2p$，也就是 $p=\frac{1}{2}$。所以：**你覺得它比較可能是正確選項（$p>\frac{1}{2}$）就劃，比較可能是錯的就不劃。** 例如 $p=0.8$ 時，劃它的期望值是 $4.6$ 分，不劃只有 $3.4$ 分。

<Graph desc="橫軸是你估計這個選項是正確選項的機率 p（0 到 1），縱軸是期望得分。藍線是劃它的期望值 y=3+2p，從 (0, 3) 升到 (1, 5)；另一條線是不劃的期望值 y=5−2p，從 (0, 5) 降到 (1, 3)。兩線交於 (1/2, 4)：交點左邊不劃的線比較高，右邊劃它的線比較高。拉動滑桿 p，兩個點標出這時兩種做法的期望值；p=0.8 時劃它是 4.6 分、不劃是 3.4 分。" x={[-0.08, 1.08]} y={[2.7, 5.3]}

  functions={[{ expr: '3+2*x', domain: [0, 1] }, { expr: '5-2*x', domain: [0, 1] }]}
  lines={[{ through: [['p', 0], ['p', 1]], color: 'ink', dashed: true }]}
  points={[{ at: ['p', '3+2*p'], label: '劃', color: 'blue' }, { at: ['p', '5-2*p'], label: '不劃', color: 'red' }, { at: [0.5, 4], label: '(1/2, 4)', color: 'amber' }]} />

這就是今天的重點：「不劃」不是保守，而是另一個判斷。劃與不劃，都要選你覺得比較可能對的那一邊。

<Perspective title="換個角度：只看「判斷對」的機率">

不論劃或不劃，這個選項判斷對就得 $5$ 分、判斷錯就得 $3$ 分。設你對它判斷對的機率是 $q$，期望值就是

$$
5q+3(1-q)=3+2q
$$

所以期望值只看 $q$：判斷對的機率越大越好。劃它時判斷對的機率是 $p$，不劃時是 $1-p$，於是只要在 $p$ 和 $1-p$ 中選比較大的那一邊，這就是「$p>\frac{1}{2}$ 就劃」。也可以直接相減：$(3+2p)-(5-2p)=4p-2$，$p>\frac{1}{2}$ 時是正的，劃它比較好。

選對邊之後的期望值是 $4+2\left|p-\frac{1}{2}\right|$：$p\ge\frac{1}{2}$ 時它等於 $3+2p$，$p<\frac{1}{2}$ 時等於 $5-2p$，畫出來像一個 V。

<Graph desc="實線是照比較可能對的那一邊作答時的期望值 y=4+2|p−1/2|，形狀像 V：p=0 或 p=1 時是 5 分，最低點在 (1/2, 4)。兩條虛線是 y=3+2p 與 y=5−2p，V 就是它們比較高的那一段。拉動滑桿 p，紅點沿著 V 移動；p=0.55 時是 4.1 分。" x={[-0.08, 1.08]} y={[2.7, 5.3]}
  params={[{ name: 'p', label: '它是正確選項的機率 p', min: 0, max: 1, step: 0.05, value: 0.55 }]}
  functions={[{ expr: '4+2*abs(x-0.5)', domain: [0, 1], color: 'red' }, { expr: '3+2*x', domain: [0, 1], dashed: true, color: 'ink' }, { expr: '5-2*x', domain: [0, 1], dashed: true, color: 'ink' }]}
  points={[{ at: ['p', '4+2*abs(p-0.5)'], color: 'red' }, { at: [0.5, 4], label: '(1/2, 4)', color: 'amber' }]} />

V 的兩側告訴你：越有把握（$p$ 越接近 $0$ 或 $1$），選對邊的好處越大；越接近 $\frac{1}{2}$，兩邊差越少。$p=0.55$ 時劃它是 $4.1$ 分、不劃是 $3.9$ 分，只差 $0.2$ 分。真的拿不定主意時，隨便選一邊就好，別在這個選項上耗時間。

</Perspective>

<StudentAsks q="如果五個選項我完全沒概念，還要作答嗎？">

要。假設你每個選項都用猜的，每個判斷對的機率是 $\frac{1}{2}$、彼此獨立，判斷錯的個數 $k$ 是 $0,1,2$ 的機率分別是 $\frac{1}{32}$、$\frac{5}{32}$、$\frac{10}{32}$，得分期望值是

$$
5\times\tfrac{1}{32}+3\times\tfrac{5}{32}+1\times\tfrac{10}{32}=\tfrac{30}{32}=\tfrac{15}{16}\text{ 分}
$$

（$k\ge 3$ 都是 $0$ 分）。嚴格來說，如果猜的結果是五個都沒劃，就等於空白，得 $0$ 分；所以正確答案只有一個或兩個選項時，期望值會再少一點，分別是 $\frac{27}{32}$ 分和 $\frac{29}{32}$ 分。不論哪一種，都不到 $1$ 分，但比空著的 $0$ 分多。不過，能排除一個選項就排除一個：每多一個有把握的判斷，期望值都會往上加。

</StudentAsks>

<Perspective title="用槓桿看：如果沒有「最低 0 分」">

先假裝負分照算。五個選項都用猜的時，$k=0,1,2,3,4,5$ 的得分是 $5$、$3$、$1$、$-1$、$-3$、$-5$，機率是 $\frac{1}{32}$、$\frac{5}{32}$、$\frac{10}{32}$、$\frac{10}{32}$、$\frac{5}{32}$、$\frac{1}{32}$。把機率當成重量，放在數線上得分的位置，整組左右對稱，平衡點就在 $0$：

$$
5\cdot\tfrac{1}{32}+3\cdot\tfrac{5}{32}+1\cdot\tfrac{10}{32}+(-1)\cdot\tfrac{10}{32}+(-3)\cdot\tfrac{5}{32}+(-5)\cdot\tfrac{1}{32}=0
$$

也就是說，這個計分方式本來設計成「完全亂猜，平均 $0$ 分」。真正讓亂猜有分的是「負數以 $0$ 分計」：把左邊三根推到 $0$，期望值增加

$$
1\cdot\tfrac{10}{32}+3\cdot\tfrac{5}{32}+5\cdot\tfrac{1}{32}=\tfrac{30}{32}=\tfrac{15}{16}
$$

剛好是上面算出的 $\frac{15}{16}$ 分。

<Perspective later title="用期望值的線性性質：不計最低 0 分時，任何多選題亂猜都平均 0 分" needs="隨機變數期望值的線性性質（選修小技巧）">

把 $k$ 拆成五個選項各自的貢獻：第 $i$ 個選項判斷錯記 $X_i=1$、判斷對記 $X_i=0$，則 $k=X_1+X_2+\cdots+X_5$。亂猜時每個 $X_i$ 的期望值是 $\frac{1}{2}$，由線性性質 $E(X+Y)=E(X)+E(Y)$ 得 $E(k)=\frac{5}{2}$。不計最低 $0$ 分時，得分 $5-2k$ 的期望值是 $5-2E(k)=0$。

換成 $n$ 個選項也一樣：$E(k)=\frac{n}{2}$，得分比例 $\frac{n-2k}{n}$ 的期望值是 $\frac{n-2\cdot\frac{n}{2}}{n}=0$。所以不論幾個選項，這個計分方式都讓亂猜平均 $0$ 分，亂猜多出來的分數全部來自「最低 $0$ 分」。
