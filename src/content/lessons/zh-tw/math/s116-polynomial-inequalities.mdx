## 先熱身：一次不等式

解一次不等式和解方程式差不多，只有一個要小心的地方：**兩邊同乘或同除以負數，不等號要反向**。

**例題**　解 $-3x+6\le 12-x$。

移項得 $-2x\le 6$。兩邊同除以 $-2$，不等號反向：$x\ge -3$。

解的範圍可以用「實數與絕對值」那章的區間寫法表示：$x\ge -3$ 寫成 $[-3,\infty)$。中括號表示包含端點，小括號表示不包含，$\infty$ 那一端永遠用小括號。課綱中，區間符號只用來表達解的範圍。

<NumberLine desc="x≥−3 的解：從 −3 開始（實心點，包含 −3）一直往右延伸。" from={-6} to={4} intervals={[{ a: -3, b: 'inf', open: [false, false] }]} />

<Perspective title="用圖形看：兩條直線比高低">

把不等式的兩邊各看成一條直線：$y=-3x+6$ 和 $y=12-x$。不等式 $-3x+6\le 12-x$ 問的是：哪些 $x$ 會讓第一條直線**不高於**第二條？

兩條直線交在 $-3x+6=12-x$，也就是 $x=-3$，交點是 $(-3,15)$。第一條的斜率是 $-3$，比第二條的 $-1$ 下降得快，所以在交點右邊，第一條直線在下方；在交點左邊，它在上方。答案是交點和它的右邊：$x\ge -3$，和移項的結果一樣。

<Graph desc="直線 y=−3x+6（較陡）與 y=12−x 交於 (−3, 15)。在 x=−3 及其右邊，y=−3x+6 不高於 y=12−x；x 軸上的紅色線段標出解 x≥−3。" x={[-6, 4]} y={[-8, 26]}
  functions={[{ expr: '-3*x+6' }, { expr: '12-x' }]}
  points={[{ at: [-3, 15], label: '(−3, 15)' }]}
  segments={[{ from: [-3, 0], to: [4, 0], color: 'red' }]}
  labels={[{ at: [1.5, 1.5], text: 'y=−3x+6' }, { at: [1.5, 10.5], text: 'y=12−x' }]} />

如果把兩邊相減，$(-3x+6)-(12-x)=-2x-6$，問題就變成「直線 $y=-2x-6$ 在 $x$ 軸下方或在 $x$ 軸上」。這條直線往右下降，過 $(-3,0)$，所以 $x\ge -3$。這正是本章後面的想法：把不等式變成「$f(x)$ 和 $0$ 比大小」，再看圖形在 $x$ 軸的哪一側。

</Perspective>

## 二次不等式：看拋物線在 $x$ 軸的哪一側

設<Term t="math.quadratic-function">二次函數</Term> $f(x)=ax^2+bx+c$，而且 $a>0$（如果 $a<0$，先兩邊同乘以 $-1$，不等號反向）。$y=f(x)$ 的圖形是開口向上的拋物線，它和 $x$ 軸的關係由判別式 $D=b^2-4ac$ 決定：

| 判別式 | 圖形和 $x$ 軸 | $f(x)>0$ | $f(x)<0$ |
|---|---|---|---|
| $D>0$，兩根 $\alpha<\beta$ | 交於兩點 | $x<\alpha$ 或 $x>\beta$ | $\alpha<x<\beta$ |
| $D=0$，重根 $\alpha$ | 切於一點 | $x\ne\alpha$ 的所有實數 | 無解 |
| $D<0$ | 沒有交點 | 所有實數 | 無解 |

<Graph desc="拉動 c 看 y=x²−2x+c：頂點在 (1, c−1)，判別式 D=4−4c。c<1 時頂點在 x 軸下方，拋物線和 x 軸交於兩點（D>0）；c=1 時剛好切於 (1, 0)（D=0）；c>1 時整條拋物線都在 x 軸上方（D<0），x²−2x+c>0 對所有實數都成立。" x={[-3, 5]} y={[-4, 6]}
  params={[{ name: 'c', min: -2, max: 3, step: 0.5, value: -2 }]}
  functions={[{ expr: 'x^2-2*x+c' }]}
  points={[{ at: ['1', 'c-1'], label: '頂點' }]} />

題目若是 $\ge$ 或 $\le$，就再把 $f(x)=0$ 的根加進答案。例如 $D=0$ 時，$f(x)\ge 0$ 的解是所有<Term t="math.real-number">實數</Term>，$f(x)\le 0$ 的解只有 $x=\alpha$。

**例題**　解 $2x^2-x-6\le 0$。

因式分解：$2x^2-x-6=(2x+3)(x-2)$，兩根是 $-\frac{3}{2}$ 和 $2$。開口向上，「小於或等於 $0$」取兩根之間，含端點：

$$
-\frac{3}{2}\le x\le 2,\quad\text{也就是}\quad \left[-\tfrac{3}{2},\,2\right]
$$

<Graph desc="拋物線 y=2x²−x−6 開口向上，和 x 軸交於 (−3/2, 0) 與 (2, 0)，最低點在 (1/4, −49/8)。兩根之間的圖形在 x 軸下方，x 軸上的紅色線段標出解 −3/2≤x≤2。" x={[-3, 4]} y={[-7, 6]}
  functions={[{ expr: '2*x^2-x-6' }]}
  points={[{ at: [-1.5, 0], label: '−3/2' }, { at: [2, 0], label: '2' }]}
  segments={[{ from: [-1.5, 0], to: [2, 0], color: 'red' }]} />

<NumberLine desc="2x²−x−6≤0 的解：−3/2 到 2 之間，兩端都是實心點（包含端點）。" from={-3} to={3} step={0.5} labelEvery={2} intervals={[{ a: -1.5, b: 2, open: [false, false] }]} points={[{ x: -1.5, label: '−3/2' }]} />

<Perspective title="不畫圖：兩個因式一正一負">

$(2x+3)(x-2)\le 0$ 表示兩個因式的乘積不是正的：不是其中一個等於 $0$，就是一正一負。分成兩種情況：

- $2x+3\ge 0$ 且 $x-2\le 0$：$x\ge -\frac{3}{2}$ 且 $x\le 2$，得 $-\frac{3}{2}\le x\le 2$。
- $2x+3\le 0$ 且 $x-2\ge 0$：$x\le -\frac{3}{2}$ 且 $x\ge 2$，沒有這樣的 $x$。

合起來就是 $-\frac{3}{2}\le x\le 2$，和看圖的答案相同。這個做法只用到「同號相乘為正、異號相乘為負」，可是因式一多，情況就會變多，所以高次式改用後面數線上的符號判斷，它其實就是把這些情況一次整理好。

</Perspective>

**例題**　解 $-x^2+2x+8<0$。

首項係數是負的，先同乘以 $-1$，不等號反向：$x^2-2x-8>0$，也就是 $(x+2)(x-4)>0$。「大於 $0$」取兩根之外：$x<-2$ 或 $x>4$。

<StudentAsks q="解x²>3x時，可以兩邊同除以x，得到x>3嗎？">

不行。$x$ 可能是正的、負的或 $0$，你不知道要不要把不等號反向。正確的做法是全部移到同一邊再分解：$x^2-3x>0$，$x(x-3)>0$，解是 $x<0$ 或 $x>3$。代 $x=-1$ 檢查：$1>-3$ 確實成立，可是 $-1$ 不滿足 $x>3$，所以除以 $x$ 會把解弄丟。

</StudentAsks>

### 恆正與恆負

「對所有實數 $x$，$ax^2+bx+c>0$ 都成立」，意思是整條拋物線都在 $x$ 軸上方。這需要開口向上，而且和 $x$ 軸沒有交點：$a>0$ 且 $D<0$。同理，恆負需要 $a<0$ 且 $D<0$。

**例題**　若 $x^2+kx+4>0$ 對所有實數 $x$ 都成立，求 $k$ 的範圍。

首項係數 $1>0$，所以只要 $D=k^2-16<0$，即 $(k+4)(k-4)<0$，得 $-4<k<4$。

<Perspective title="用配方看：最低點在 x 軸上方">

不用判別式，也可以直接配方：

$$
x^2+kx+4=\left(x+\frac{k}{2}\right)^2+4-\frac{k^2}{4}
$$

第一項一定 $\ge 0$，在 $x=-\frac{k}{2}$ 時等於 $0$，所以整個式子的最小值是 $4-\frac{k^2}{4}$，也就是頂點的 $y$ 坐標。要對所有 $x$ 都大於 $0$，只要最小值大於 $0$：$4-\frac{k^2}{4}>0$，$k^2<16$，得 $-4<k<4$。

兩種做法其實是同一件事：$y=ax^2+bx+c$ 的頂點 $y$ 坐標是 $-\frac{D}{4a}$，當 $a>0$ 時，「頂點在 $x$ 軸上方」就是「$D<0$」。

<Graph desc="拉動 k 看 y=x²+kx+4：頂點在 (−k/2, 4−k²/4)。−4<k<4 時頂點在 x 軸上方，整條拋物線都在 x 軸上方；k=4 或 k=−4 時頂點落在 x 軸上，拋物線切於 x 軸；|k|>4 時頂點在 x 軸下方，有一段 x 使 x²+kx+4<0。" x={[-6, 6]} y={[-6, 10]}
  params={[{ name: 'k', min: -6, max: 6, step: 0.5, value: 2 }]}
  functions={[{ expr: 'x^2+k*x+4' }]}
  points={[{ at: ['-k/2', '4-k^2/4'], label: '頂點' }]} />

</Perspective>

## 高次不等式：在數線上判斷符號

課綱中的高次多項式不等式，只處理已經分解好的式子。做法是把根標在數線上，看每一段的正負：

1. 把所有根由小到大標在數線上，數線被切成好幾段。
2. 最右邊那一段（$x$ 很大時），正負由最高次項決定。首項係數為正，就是正的。這和上一章「圖形的大域特徵由最高次項決定」是同一件事。
3. 往左每經過一個**單根**（只出現一次的根），正負就改變一次。

**例題**　解 $(x+2)(x-1)(x-3)>0$。

根是 $-2$、$1$、$3$。$x>3$ 時三個因式都是正的，乘積為正；往左依序變號：

| 範圍 | $x<-2$ | $-2<x<1$ | $1<x<3$ | $x>3$ |
|---|---|---|---|---|
| $(x+2)(x-1)(x-3)$ 的正負 | $-$ | $+$ | $-$ | $+$ |

所以解是 $-2<x<1$ 或 $x>3$，寫成 $(-2,1)\cup(3,\infty)$。用一個點檢查：$x=0$ 時乘積是 $(2)(-1)(-3)=6>0$，$0$ 確實在解裡。從圖形看，<Term t="math.polynomial-function">多項式函數</Term> $y=(x+2)(x-1)(x-3)$ 的圖形從左下方往右上方走，依序穿過 $x$ 軸三次，解就是圖形在 $x$ 軸上方的那兩段。

<Graph desc="三次函數 y=(x+2)(x−1)(x−3) 的圖形從左下方往右上方走，依序在 x=−2、1、3 穿過 x 軸。圖形在 x 軸上方的是 −2<x<1 和 x>3 兩段，x 軸上的紅色線段標出這兩段解。" x={[-3, 4.5]} y={[-6, 10]}
  functions={[{ expr: '(x+2)*(x-1)*(x-3)' }]}
  points={[{ at: [-2, 0], label: '−2' }, { at: [1, 0], label: '1' }, { at: [3, 0], label: '3' }]}
  segments={[{ from: [-2, 0], to: [1, 0], color: 'red' }, { from: [3, 0], to: [4.5, 0], color: 'red' }]} />

<NumberLine desc="(x+2)(x−1)(x−3)>0 的解：−2 到 1 之間（兩端空心，不含），以及 3 的右邊（3 空心，不含）。" from={-4} to={5} intervals={[{ a: -2, b: 1, open: [true, true] }, { a: 3, b: 'inf', open: [true, false] }]} />

<Perspective title="換個表示法：數負的因式有幾個">

把每個因式的正負各寫一列。乘積的正負只看**負的因式有幾個**：偶數個就是正，奇數個就是負。

| 範圍 | $x<-2$ | $-2<x<1$ | $1<x<3$ | $x>3$ |
|---|---|---|---|---|
| $x+2$ | $-$ | $+$ | $+$ | $+$ |
| $x-1$ | $-$ | $-$ | $+$ | $+$ |
| $x-3$ | $-$ | $-$ | $-$ | $+$ |
| 負的因式個數 | $3$ | $2$ | $1$ | $0$ |
| 乘積 | $-$ | $+$ | $-$ | $+$ |

每個因式 $x-r$ 只在 $x=r$ 這一點改變正負（左邊負、右邊正）。所以往左經過一個單根，負的因式就多一個，乘積變號，這就是「從最右邊往左變號」的理由。如果因式是 $(x-1)^2=(x-1)(x-1)$，經過 $x=1$ 時負的因式一次多兩個，奇偶不變，所以**不變號**：下一節的重根規則也從這裡來。

</Perspective>

### 重根：碰到 $x$ 軸但不穿過

如果某個因式是平方，例如 $(x-1)^2$，它除了 $x=1$ 以外都是正的，所以經過 $x=1$ 時**不變號**。圖形在這裡只是碰到 $x$ 軸又彈回去。

<Graph desc="拉動 r：y=(x−r)(x−1)(x+3) 和 x 軸交於 −3、1、r 三點。把 r 移到 1，兩個根合成重根，圖形變成 y=(x−1)²(x+3)，在 (1, 0) 只碰到 x 軸又彈回去、不穿過；這時圖形在 x 軸上方的部分是 x>−3 且 x≠1。" x={[-4, 3.5]} y={[-10, 14]}
  params={[{ name: 'r', min: -2, max: 3, step: 0.25, value: 2 }]}
  functions={[{ expr: '(x-r)*(x-1)*(x+3)' }]}
  points={[{ at: [-3, 0], label: '−3' }, { at: [1, 0], label: '1' }, { at: ['r', 0], label: 'r' }]} />

**例題**　解 $(x-1)^2(x+3)>0$。

$(x-1)^2\ge 0$，只在 $x=1$ 時等於 $0$。所以乘積為正，要 $x+3>0$ 而且 $x\ne 1$：解是 $x>-3$ 且 $x\ne 1$，寫成 $(-3,1)\cup(1,\infty)$。

<NumberLine desc="(x−1)²(x+3)>0 的解：−3 的右邊全部，但挖掉 x=1；−3 和 1 都是空心點（不含）。" from={-5} to={4} intervals={[{ a: -3, b: 1, open: [true, true] }, { a: 1, b: 'inf', open: [true, false] }]} />

同一個式子如果改成 $(x-1)^2(x+3)\ge 0$，$x=1$ 會讓乘積等於 $0$，符合「等於」，所以解變成 $x\ge -3$。**重根處要不要包含，取決於有沒有等號。**

<StudentAsks q="因式裡x的係數是負的，例如(2−x)，還能用符號判斷嗎？">

可以，但要先整理。$(2-x)=-(x-2)$，把負號提出來後，兩邊同乘以 $-1$，不等號反向，就回到每個因式的 $x$ 係數都是正的樣子。直接硬做也行，只是最右邊那一段的正負要重新判斷，比較容易出錯。

</StudentAsks>
