## 平面：一個點加一個法向量

和平面垂直的非零向量，叫做這個平面的<Term t="math.normal-vector">法向量</Term>。課綱在平面方程式這一節列出三件事：平面的法向量與標準式、兩平面的夾角、點到平面的距離。下面依序複習。

通過點 $P_0(x_0,y_0,z_0)$、法向量為 $\vec{n}=(a,b,c)$ 的平面，平面上任一點 $P(x,y,z)$ 都滿足 $\overrightarrow{P_0P}\perp\vec{n}$，也就是<Term t="math.inner-product">內積</Term>為 $0$：

$$
a(x-x_0)+b(y-y_0)+c(z-z_0)=0
$$

這叫做點法式。展開整理就是 $ax+by+cz+d=0$ 的樣子。反過來，看到平面 $ax+by+cz+d=0$，就能直接讀出法向量 $(a,b,c)$；它的任何非零倍數也都是法向量。

**例題**　求通過 $A(1,2,0)$、$B(2,0,1)$、$C(0,1,3)$ 三點的平面方程式。

法向量要同時垂直 $\overrightarrow{AB}=(1,-2,1)$ 與 $\overrightarrow{AC}=(-1,-1,3)$，所以用<Term t="math.cross-product">外積</Term>：

$$
\overrightarrow{AB}\times\overrightarrow{AC}=(-5,-4,-3)
$$

取法向量 $(5,4,3)$，用點法式代入 $A$：$5(x-1)+4(y-2)+3z=0$，即 $5x+4y+3z-13=0$。驗算：$B$ 代入得 $10+0+3=13$，$C$ 代入得 $0+4+9=13$，都在平面上。

<Space3D desc="三角形 ABC 是平面 5x+4y+3z=13 的一小塊，頂點 A(1, 2, 0)、B(2, 0, 1)、C(0, 1, 3)。從 A 出發畫出 AB=(1, −2, 1) 與 AC=(−1, −1, 3) 兩個向量，它們都躺在平面裡；第三個箭頭是法向量 n=(5, 4, 3)，畫成一半長度，從 A 指向 (3.5, 4, 1.5)，和平面裡的兩個向量都垂直。" range={4}
  planes={[{ corners: [[1, 2, 0], [2, 0, 1], [0, 1, 3]], label: 'E' }]}
  vectors={[{ tail: [1, 2, 0], tip: [2, 0, 1], label: 'AB', color: 'blue' }, { tail: [1, 2, 0], tip: [0, 1, 3], label: 'AC', color: 'blue' }, { tail: [1, 2, 0], tip: [3.5, 4, 1.5], label: 'n', color: 'amber' }]}
  points={[{ at: [1, 2, 0], label: 'A' }, { at: [2, 0, 1], label: 'B' }, { at: [0, 1, 3], label: 'C' }]} />

<Perspective title="不用外積：設 ax+by+cz=d，代入三點解聯立">

平面可以寫成 $ax+by+cz=d$。三點都在平面上，代入得到

$$
a+2b=d,\qquad 2a+c=d,\qquad b+3c=d
$$

三個式子有四個未知數，因為平面方程式同乘一個非零數還是同一個平面，所以可以先取一個方便的值。由第二式 $c=d-2a$，代入第三式得 $b=d-3c=6a-2d$，再代入第一式：$a+12a-4d=d$，即 $13a=5d$。取 $d=13$，得 $a=5$、$b=4$、$c=3$，平面是 $5x+4y+3z=13$，和外積的結果相同。

這個做法只用代入消去，不必記外積；缺點是要解三元的聯立。外積一步就給出法向量，三點坐標比較亂時通常比較快。

</Perspective>

## 兩平面的夾角

兩個平面的夾角，就看它們法向量的夾角。設法向量是 $\vec{n}_1$、$\vec{n}_2$，則

$$
\cos\theta=\frac{\vec{n}_1\cdot\vec{n}_2}{\lvert\vec{n}_1\rvert\,\lvert\vec{n}_2\rvert}
$$

兩個相交平面會形成 $\theta$ 與 $180^\circ-\theta$ 兩個夾角，兩者互補。特別地：

- 法向量平行 $\iff$ 兩平面平行或重合；
- 法向量垂直（內積為 $0$）$\iff$ 兩平面垂直。

**例題**　求平面 $x+z=2$ 與 $y+z=5$ 的夾角。

法向量是 $(1,0,1)$ 與 $(0,1,1)$，內積 $1$，長度都是 $\sqrt{2}$，所以 $\cos\theta=\frac{1}{\sqrt{2}\cdot\sqrt{2}}=\frac{1}{2}$，$\theta=60^\circ$。兩平面的夾角是 $60^\circ$ 與 $120^\circ$。

把視線放在交線的方向上，兩個平面都「側著」看，各縮成一條直線，交線縮成一個點。每個法向量和自己的平面垂直，所以在這張側視圖裡，法向量就是把平面那條線轉 $90^\circ$。兩條線都轉 $90^\circ$，它們之間的夾角不變，所以法向量的夾角等於兩平面的夾角（或它的補角）。

<Perspective title="在兩個平面裡直接量角">

兩平面的夾角，原本的意思是：在交線上取一點，在兩個平面裡各畫一條和交線垂直的射線，量這兩條射線的夾角。可以照這個定義直接算。

交線同時在兩平面上，方向和兩個法向量都垂直：$\vec{d}=\vec{n}_1\times\vec{n}_2=(1,0,1)\times(0,1,1)=(-1,-1,1)$。在第一個平面裡、和交線垂直的方向要同時垂直 $\vec{n}_1$ 與 $\vec{d}$，所以取

$$
\vec{u}_1=\vec{n}_1\times\vec{d}=(1,-2,-1),\qquad \vec{u}_2=\vec{n}_2\times\vec{d}=(2,-1,1)
$$

驗算：$\vec{u}_1\cdot\vec{n}_1=1-1=0$、$\vec{u}_1\cdot\vec{d}=-1+2-1=0$；$\vec{u}_2\cdot\vec{n}_2=-1+1=0$、$\vec{u}_2\cdot\vec{d}=-2+1+1=0$。於是

$$
\cos\theta=\frac{\vec{u}_1\cdot\vec{u}_2}{\lvert\vec{u}_1\rvert\,\lvert\vec{u}_2\rvert}=\frac{2+2-1}{\sqrt{6}\cdot\sqrt{6}}=\frac{1}{2}
$$

$\theta=60^\circ$，和用法向量算的一樣。這個做法步驟比較多，但它就是夾角的定義；用法向量只是捷徑。

## 點到平面的距離

點 $P(x_0,y_0,z_0)$ 到平面 $E:ax+by+cz+d=0$ 的距離是

$$
d(P,E)=\frac{\lvert ax_0+by_0+cz_0+d\rvert}{\sqrt{a^2+b^2+c^2}}
$$

和坐標平面上「點到直線的距離」長得幾乎一樣，只是多了 $z$ 那一項。兩平行平面 $ax+by+cz+d_1=0$ 與 $ax+by+cz+d_2=0$ 的距離是 $\frac{\lvert d_1-d_2\rvert}{\sqrt{a^2+b^2+c^2}}$；和直線的情形一樣，**係數要先調成完全相同**（包括正負號）。

**例題**　求點 $P(4,-1,3)$ 到平面 $E:2x-y+2z+3=0$ 的距離。

$$
d(P,E)=\frac{\lvert 8+1+6+3\rvert}{\sqrt{4+1+4}}=\frac{18}{3}=6
$$

<Space3D desc="平面 E：2x−y+2z+3=0 的一塊，四個角是 (4, 5, −3)、(0, 5, 1)、(−4, −3, 1)、(0, −3, −3)。點 P(4, −1, 3) 在平面上方，虛線 PH 垂直平面，垂足 H(0, 1, −1)，長度 6，就是 P 到 E 的距離。從 H 出發的箭頭是法向量 n=(2, −1, 2)，指向 (2, 0, 1)；PH 和 n 平行，長度是 n 的 2 倍。" range={5}
  planes={[{ corners: [[4, 5, -3], [0, 5, 1], [-4, -3, 1], [0, -3, -3]], label: 'E' }]}
  segments={[{ from: [4, -1, 3], to: [0, 1, -1], dashed: true }]}
  vectors={[{ tail: [0, 1, -1], tip: [2, 0, 1], label: 'n', color: 'amber' }]}
  points={[{ at: [4, -1, 3], label: 'P' }, { at: [0, 1, -1], label: 'H' }]} />

<Perspective title="用柯西不等式：距離是最短的那一段">

距離的意思是「$P$ 到平面上所有點的長度中最短的」。設 $(x,y,z)$ 在 $E$ 上，則 $2x-y+2z=-3$，所以

$$
2(x-4)-(y+1)+2(z-3)=(2x-y+2z)-15=-18
$$

由<Term t="math.cauchy-inequality">柯西不等式</Term>，

$$
\left[(x-4)^2+(y+1)^2+(z-3)^2\right](2^2+1^2+2^2)\ge(-18)^2
$$

左邊的方括號就是 $P$ 到 $(x,y,z)$ 距離的平方，所以距離平方 $\ge\frac{324}{9}=36$，距離 $\ge 6$。等號成立時 $(x-4,y+1,z-3)$ 和 $(2,-1,2)$ 平行，也就是沿法向量走：這正是垂足。最短距離是 $6$，和公式一致。這個看法把距離公式和「求最小值」連在一起。

</Perspective>

**例題**　求兩平行平面 $2x-y+2z+3=0$ 與 $4x-2y+4z-6=0$ 的距離。

第二個平面除以 $2$，變成 $2x-y+2z-3=0$。距離是 $\frac{\lvert 3-(-3)\rvert}{3}=2$。

<StudentAsks q="點到平面的距離公式是怎麼來的？">

在平面上取一點 $Q$，距離就是 $\overrightarrow{QP}$ 在法向量 $\vec{n}$ 方向上的投影長，也就是 $\frac{\lvert\overrightarrow{QP}\cdot\vec{n}\rvert}{\lvert\vec{n}\rvert}$。因為 $Q$ 在平面上，$\overrightarrow{QP}\cdot\vec{n}$ 整理後剛好是 $ax_0+by_0+cz_0+d$，所以得到上面的公式。這個「投影到法向量上」的想法，最後一節算歪斜線的距離時還會再用一次。

</StudentAsks>

## 空間直線：參數式與比例式

空間中的直線由**一點**和**一個方向向量**決定。通過 $P_0(x_0,y_0,z_0)$、方向向量為 $\vec{v}=(l,m,n)$ 的直線，<Term t="math.parametric-equation-of-line">參數式</Term>是

$$
x=x_0+lt,\quad y=y_0+mt,\quad z=z_0+nt\quad(t\text{ 為實數})
$$

每一個 $t$ 對應直線上的一個點。若 $l$、$m$、$n$ 都不是 $0$，把三個式子都解出 $t$，就得到<Term t="math.symmetric-equation-of-line">比例式</Term>：

$$
\frac{x-x_0}{l}=\frac{y-y_0}{m}=\frac{z-z_0}{n}
$$

**例題**　求通過 $A(1,-1,2)$ 與 $B(3,0,1)$ 的直線。

方向向量 $\overrightarrow{AB}=(2,1,-1)$。參數式是 $x=1+2t$，$y=-1+t$，$z=2-t$；比例式是

$$
\frac{x-1}{2}=\frac{y+1}{1}=\frac{z-2}{-1}
$$

$t=1$ 時得到 $(3,0,1)$，正是 $B$。

<Space3D desc="直線 x=1+2t、y=−1+t、z=2−t 畫成從 t=−1 的點 (−1, −2, 3) 到 t=2 的點 (5, 1, 0) 的線段。A(1, −1, 2) 是 t=0，B(3, 0, 1) 是 t=1，箭頭 v=(2, 1, −1) 從 A 指到 B。t 每增加 1，點就沿著 v 再走一步。" range={5}
  segments={[{ from: [-1, -2, 3], to: [5, 1, 0] }]}
  vectors={[{ tail: [1, -1, 2], tip: [3, 0, 1], label: 'v', color: 'amber' }]}
  points={[{ at: [-1, -2, 3], label: 't=−1' }, { at: [1, -1, 2], label: 'A（t=0）' }, { at: [3, 0, 1], label: 'B（t=1）' }, { at: [5, 1, 0], label: 't=2' }]} />

<Perspective title="比例式其實是兩個平面">

比例式 $\frac{x-1}{2}=\frac{y+1}{1}=\frac{z-2}{-1}$ 有兩個等號，拆開就是兩個一次方程式：

- $\frac{x-1}{2}=y+1$，整理得 $x-2y=3$；
- $y+1=\frac{z-2}{-1}$，整理得 $y+z=1$。

每一個都是一個平面，所以這條直線就是平面 $x-2y=3$ 和 $y+z=1$ 的交線。驗算：$A(1,-1,2)$ 代入得 $1+2=3$、$-1+2=1$；$B(3,0,1)$ 代入得 $3-0=3$、$0+1=1$。反過來，看到兩個平面聯立，也可以想成一條直線，「動手試試」那一題就是這樣。

<Space3D desc="平面 x−2y=3（和 z 軸平行的直立平面）與平面 y+z=1（和 x 軸平行的斜平面）各畫一塊，兩塊交在從 (−1, −2, 3) 到 (5, 1, 0) 的線段上，就是通過 A(1, −1, 2) 與 B(3, 0, 1) 的直線。" range={5}

  segments={[{ from: [-1, -2, 3], to: [5, 1, 0] }]}
  points={[{ at: [1, -1, 2], label: 'A' }, { at: [3, 0, 1], label: 'B' }]} />

</Perspective>

<StudentAsks q="同一條直線，我和課本寫出來的參數式不一樣，是我錯了嗎？">

不一定。直線上的點可以任選，方向向量也可以換成任何非零倍數，所以同一條直線有很多種參數式。檢查的方法是：兩個方向向量是否平行，以及你的式子裡的一點是否在對方的直線上。另外，如果方向向量有一個分量是 $0$，例如 $(2,0,1)$，就不能寫成分母是 $0$ 的比例式，要把那一個坐標單獨寫成 $y=y_0$。

</StudentAsks>

## 直線與平面的關係

設直線 $L$ 的方向向量是 $\vec{v}$，平面 $E$ 的法向量是 $\vec{n}$：

| 情況 | 判斷 | 交點 |
|---|---|---|
| 相交 | $\vec{v}\cdot\vec{n}\ne 0$ | 恰一個 |
| 平行 | $\vec{v}\cdot\vec{n}=0$，且 $L$ 上的點不在 $E$ 上 | 沒有 |
| $L$ 落在 $E$ 上 | $\vec{v}\cdot\vec{n}=0$，且 $L$ 上的點在 $E$ 上 | 無限多個 |

其中 $\vec{v}$ 和 $\vec{n}$ 平行時，$L$ 垂直 $E$。求交點只要把參數式代入平面，解出 $t$。

**例題**　求直線 $x=1+2t$，$y=-1+t$，$z=2-t$ 與平面 $x+y+z=6$ 的交點。

代入：$(1+2t)+(-1+t)+(2-t)=2+2t=6$，$t=2$，交點是 $(5,1,0)$。驗算 $5+1+0=6$。

<Space3D desc="平面 x+y+z=6 的一塊，四個角是 (7, 1, −2)、(4, −2, 4)、(1, 1, 4)、(4, 4, −2)。直線 x=1+2t、y=−1+t、z=2−t 畫成從 t=−1 的點 (−1, −2, 3) 到 t=3 的點 (7, 2, −1) 的線段，在 t=2 的點 (5, 1, 0) 穿過平面。A(1, −1, 2) 是 t=0 的點，在平面的一側。" range={5}
  planes={[{ corners: [[7, 1, -2], [4, -2, 4], [1, 1, 4], [4, 4, -2]], label: 'x+y+z=6' }]}
  segments={[{ from: [-1, -2, 3], to: [7, 2, -1] }]}
  points={[{ at: [1, -1, 2], label: 'A' }, { at: [5, 1, 0], label: '(5, 1, 0)' }]} />

<Perspective title="把代入看成一次函數：斜率就是 v·n">

令 $g(t)=x+y+z-6$，把直線上 $t$ 對應的點代進去。因為坐標都是 $t$ 的一次式，$g(t)$ 是 $t$ 的一次函數：本題 $g(t)=2t-4$。交點就是 $g(t)=0$ 的根 $t=2$，也就是圖形和橫軸的交點。

一般來說，$g(t)$ 的斜率是 $\vec{v}\cdot\vec{n}$，$g(0)$ 是起點代入平面的值。表格裡的三種情況，在圖上一目了然：斜率不是 $0$，直線恰穿過橫軸一次（相交）；斜率是 $0$ 而 $g(0)\ne0$，是一條不碰橫軸的水平線（平行）；斜率和 $g(0)$ 都是 $0$，整條線就是橫軸（直線落在平面上）。

<Perspective title="三個平面交於一點：用消去法解">

前面「比例式其實是兩個平面」說過，這條直線是平面 $x-2y=3$ 和 $y+z=1$ 的交線。所以「直線和平面 $x+y+z=6$ 的交點」，就是三個平面的共同點，也就是三元一次聯立方程組

$$
x-2y=3,\qquad y+z=1,\qquad x+y+z=6
$$

的解。第三式減第二式消去 $y$、$z$，直接得 $x=5$；代回第一式 $5-2y=3$，$y=1$；再代回第二式，$z=0$。交點 $(5,1,0)$，和參數式代入的結果相同。代數上是消去未知數，幾何上是三個平面交在一點。

</Perspective>

<Perspective later title="用行列式判斷三平面是否恰交一點" needs="三元一次方程組的克拉瑪公式，以及用行列式判定三平面的關係（「矩陣」章只教二元；選修小技巧）">

把三個平面的係數排成三階行列式，它就是三個法向量 $(1,-2,0)$、$(0,1,1)$、$(1,1,1)$ 張出的平行六面體的有向體積：

$$
\Delta=\begin{vmatrix}1&-2&0\\0&1&1\\1&1&1\end{vmatrix}=-2\ne0
$$

$\Delta\ne0$ 表示三個法向量不共平面，三個平面恰交於一點。克拉瑪公式再給出 $\Delta_x=-10$、$\Delta_y=-2$、$\Delta_z=0$，所以 $x=\frac{-10}{-2}=5$、$y=\frac{-2}{-2}=1$、$z=\frac{0}{-2}=0$。

</Perspective>

**例題**　求點 $P(4,-1,3)$ 在平面 $E:2x-y+2z+3=0$ 上的投影點（垂足）。

過 $P$ 且垂直 $E$ 的直線，方向向量就是法向量 $(2,-1,2)$：$x=4+2t$，$y=-1-t$，$z=3+2t$。代入 $E$：

$$
2(4+2t)-(-1-t)+2(3+2t)+3=18+9t=0
$$

$t=-2$，垂足是 $(0,1,-1)$。$P$ 到垂足的距離是 $\lvert t\rvert\cdot\lvert\vec{n}\rvert=2\cdot 3=6$，和前面用公式算的距離相同。

<Perspective title="用正射影一步寫出垂足">

$P$ 代入平面的值是 $2\cdot4-(-1)+2\cdot3+3=18$，它等於 $\vec{n}\cdot\overrightarrow{HP}$（$H$ 是垂足，理由和距離公式的推導相同）。$\overrightarrow{HP}$ 和 $\vec{n}$ 平行，所以 $\overrightarrow{HP}=\frac{18}{\lvert\vec{n}\rvert^2}\vec{n}=\frac{18}{9}(2,-1,2)=(4,-2,4)$，於是

$$
H=P-\overrightarrow{HP}=(4,-1,3)-(4,-2,4)=(0,1,-1)
$$

不必寫參數式，也不必解 $t$。這裡的 $\frac{18}{9}=2$，正是上面解出的 $\lvert t\rvert$。

</Perspective>

## 點到直線、平行線與歪斜線的距離

這三種距離，課綱註明通常用外積來算。

**點到直線**：取直線 $L$ 上一點 $A$ 與方向向量 $\vec{v}$，$\overrightarrow{AP}$ 與 $\vec{v}$ 張出的平行四邊形面積是 $\lvert\overrightarrow{AP}\times\vec{v}\rvert$，底是 $\lvert\vec{v}\rvert$，高就是距離：

$$
d(P,L)=\frac{\lvert\overrightarrow{AP}\times\vec{v}\rvert}{\lvert\vec{v}\rvert}
$$

**兩平行線**：在其中一條線上任取一點，算它到另一條線的距離即可。

**歪斜線**：不平行也不相交的兩條直線叫做<Term t="math.skew-lines">歪斜線</Term>。設 $L_1$ 過 $A$、方向 $\vec{v}_1$，$L_2$ 過 $B$、方向 $\vec{v}_2$，則 $\vec{n}=\vec{v}_1\times\vec{v}_2$ 同時垂直兩條線，距離是 $\overrightarrow{AB}$ 在 $\vec{n}$ 上的投影長：

$$
d(L_1,L_2)=\frac{\lvert\overrightarrow{AB}\cdot\vec{n}\rvert}{\lvert\vec{n}\rvert}
$$

**例題**　求點 $P(2,0,1)$ 到直線 $L$：$x=t$，$y=t$，$z=0$ 的距離。

取 $A(0,0,0)$、$\vec{v}=(1,1,0)$，$\overrightarrow{AP}=(2,0,1)$，$\overrightarrow{AP}\times\vec{v}=(-1,1,2)$，長度 $\sqrt{6}$。距離是 $\frac{\sqrt{6}}{\sqrt{2}}=\sqrt{3}$。

<Space3D desc="直線 L：x=t、y=t、z=0 躺在 xy 平面上，畫成從 (−1, −1, 0) 到 (3, 3, 0) 的線段。從 A(0, 0, 0) 出發的兩個箭頭是 v=(1, 1, 0) 和 AP=(2, 0, 1)，它們張出的平行四邊形四個頂點是 (0, 0, 0)、(2, 0, 1)、(3, 1, 1)、(1, 1, 0)，面積 √6。以 v 為底（長 √2），高就是虛線 PQ，Q(1, 1, 0) 是垂足，PQ=√3。" range={3}
  planes={[{ corners: [[0, 0, 0], [2, 0, 1], [3, 1, 1], [1, 1, 0]], color: 'blue' }]}
  segments={[{ from: [-1, -1, 0], to: [3, 3, 0] }, { from: [2, 0, 1], to: [1, 1, 0], dashed: true }]}
  vectors={[{ tip: [1, 1, 0], label: 'v', color: 'amber' }, { tip: [2, 0, 1], label: 'AP', color: 'amber' }]}
  points={[{ at: [0, 0, 0], label: 'A' }, { at: [2, 0, 1], label: 'P' }, { at: [1, 1, 0], label: 'Q' }]} />

<Perspective title="直接找垂足，或把距離寫成二次函數">

直線上的點寫成 $Q(t,t,0)$，則 $\overrightarrow{QP}=(2-t,-t,1)$。

**找垂足**：$\overrightarrow{QP}\perp\vec{v}$，所以 $(2-t)+(-t)=0$，$t=1$，$Q(1,1,0)$，$\overrightarrow{QP}=(1,-1,1)$，長度 $\sqrt{3}$。

**配方**：$\lvert\overrightarrow{QP}\rvert^2=(2-t)^2+t^2+1=2t^2-4t+5=2(t-1)^2+3$，最小值在 $t=1$ 時取到 $3$，距離 $\sqrt{3}$。

兩種做法都不用外積，而且順便求出最近的點 $Q$；外積公式只給距離，不給垂足。

</Perspective>

**例題**　求 $x$ 軸與直線 $L_2$：$(x,y,z)=(0,1,2)+s(0,1,1)$ 的距離。

$x$ 軸過 $A(0,0,0)$、方向 $(1,0,0)$。$L_2$ 上的點 $x$ 坐標都是 $0$，要碰到 $x$ 軸必須 $y=1+s=0$ 且 $z=2+s=0$，不可能，而兩方向也不平行，所以是歪斜線。$\vec{n}=(1,0,0)\times(0,1,1)=(0,-1,1)$，$\overrightarrow{AB}=(0,1,2)$，距離是

$$
\frac{\lvert 0-1+2\rvert}{\sqrt{2}}=\frac{1}{\sqrt{2}}=\frac{\sqrt{2}}{2}
$$

<Space3D desc="x 軸畫成從 (−3, 0, 0) 到 (4, 0, 0) 的線段；L₂ 畫成從 s=−4 的點 (0, −3, −2) 到 s=2 的點 (0, 3, 4) 的線段，整條落在 yz 平面上，通過 B(0, 1, 2)。兩線不相交也不平行。虛線是公垂線段，從原點 O 到 L₂ 上 s=−3/2 的點 M(0, −1/2, 1/2)，長度 √2/2，就是兩歪斜線的距離。" range={4}

  points={[{ at: [0, 1, 2], label: 'B' }, { at: [0, -0.5, 0.5], label: 'M' }, { at: [0, 0, 0], label: 'O' }]} />

<Perspective title="順著 x 軸看過去：變成平面上點到直線的距離">

$L_2$ 上每一點的 $x$ 坐標都是 $0$，所以 $L_2$ 整條在 $yz$ 平面上，而 $x$ 軸垂直 $yz$ 平面、交於原點。順著 $x$ 軸看過去，$x$ 軸縮成一個點 $O$，問題變成 $yz$ 平面上「原點到直線的距離」。

$L_2$ 的 $y=1+s$、$z=2+s$，消去 $s$ 得 $z=y+1$，即 $y-z+1=0$。原點到它的距離是 $\frac{\lvert 0-0+1\rvert}{\sqrt{1+1}}=\frac{\sqrt{2}}{2}$，和外積算的一樣。

<Perspective title="把距離平方寫成兩個參數的函數">

$x$ 軸上的點 $(p,0,0)$ 與 $L_2$ 上的點 $(0,1+s,2+s)$ 的距離平方是

$$
p^2+(1+s)^2+(2+s)^2=p^2+2\left(s+\tfrac{3}{2}\right)^2+\tfrac{1}{2}
$$

兩個平方項各自最小是 $0$，所以 $p=0$、$s=-\frac{3}{2}$ 時最小，距離平方 $\frac{1}{2}$，距離 $\frac{\sqrt{2}}{2}$；兩個最近點就是 $O(0,0,0)$ 與 $M(0,-\frac{1}{2},\frac{1}{2})$。
