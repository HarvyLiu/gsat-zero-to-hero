## 比例的工具：相似三角形

兩個三角形若有兩組對應角相等（AA），它們就是<Term t="math.similar-triangles">相似三角形</Term>：對應邊的比都相同，這個比叫做**相似比**。平面上的比例問題，幾乎都靠下面兩個結果：

- **平行線截比例線段**：在 $\triangle ABC$ 中，$D$ 在 $\overline{AB}$ 上、$E$ 在 $\overline{AC}$ 上，且 $\overline{DE}\parallel\overline{BC}$，則 $\triangle ADE$ 與 $\triangle ABC$ 相似，
$$
\frac{\overline{AD}}{\overline{AB}}=\frac{\overline{AE}}{\overline{AC}}=\frac{\overline{DE}}{\overline{BC}}，\qquad \frac{\overline{AD}}{\overline{DB}}=\frac{\overline{AE}}{\overline{EC}}
$$
- **面積比是相似比的平方**：相似比是 $k$，面積比就是 $k^2$。

**例題**　在 $\triangle ABC$ 中，$\overline{DE}\parallel\overline{BC}$，$\overline{AD}=3$、$\overline{DB}=2$、$\overline{BC}=10$。求 $\overline{DE}$。

$\overline{AB}=3+2=5$，所以相似比 $\frac{\overline{AD}}{\overline{AB}}=\frac{3}{5}$，$\overline{DE}=\frac{3}{5}\times 10=6$。注意要用 $\overline{AD}:\overline{AB}$，不是 $\overline{AD}:\overline{DB}$。

<Graph desc="△ABC 的頂點 A(3, 4)、B(0, 0)、C(10, 0)，所以 AB=5、BC=10。D 在 AB 上、E 在 AC 上，且 AD:AB=AE:AC=t，紅色的 DE 和 BC 平行（都是水平線）。拉動 t：DE 的長度永遠是 10t，也就是 t 倍的 BC；t=0.6 時 AD=3、DB=2、DE=6，就是例題的情形。" x={[-1, 11]} y={[-1, 5]}
  params={[{ name: 't', min: 0, max: 1, step: 0.05, value: 0.6 }]}
  polygons={[{ points: [[3, 4], [0, 0], [10, 0]] }]}
  segments={[{ from: ['3-3*t', '4-4*t'], to: ['3+7*t', '4-4*t'], color: 'red' }]}
  points={[{ at: [3, 4], label: 'A' }, { at: [0, 0], label: 'B' }, { at: [10, 0], label: 'C' }, { at: ['3-3*t', '4-4*t'], label: 'D', color: 'red' }, { at: ['3+7*t', '4-4*t'], label: 'E', color: 'red' }]} />

<Perspective title="用向量看：一個式子同時得到平行與比例">

設 $\overrightarrow{AD}=s\,\overrightarrow{AB}$、$\overrightarrow{AE}=u\,\overrightarrow{AC}$（$D$ 在 $\overline{AB}$ 上、$E$ 在 $\overline{AC}$ 上）。相減：

$$
\overrightarrow{DE}=\overrightarrow{AE}-\overrightarrow{AD}=u\,\overrightarrow{AC}-s\,\overrightarrow{AB}
$$

$\overline{DE}\parallel\overline{BC}$ 表示 $\overrightarrow{DE}=\lambda\,\overrightarrow{BC}=\lambda\,\overrightarrow{AC}-\lambda\,\overrightarrow{AB}$。$\overrightarrow{AB}$、$\overrightarrow{AC}$ 不平行，同一個向量用它們表示的方法只有一種，比較係數得 $u=\lambda$、$s=\lambda$。所以

$$
s=u=\lambda,\qquad \overrightarrow{DE}=s\,\overrightarrow{BC}
$$

這一行同時說出三件事：$\overline{AD}:\overline{AB}=\overline{AE}:\overline{AC}$、$\overline{DE}\parallel\overline{BC}$、$\overline{DE}=s\cdot\overline{BC}$。用上圖的坐標驗算例題：$s=\frac{3}{5}$，$D=(3,4)+\frac{3}{5}(-3,-4)=(1.2,\,1.6)$，$E=(3,4)+\frac{3}{5}(7,-4)=(7.2,\,1.6)$，$\overrightarrow{DE}=(6,0)=\frac{3}{5}(10,0)=\frac{3}{5}\overrightarrow{BC}$，長度 $6$。

</Perspective>

### 設計：放大與縮小

把一個圖形等比例放大，就是做出一個相似的圖形。

**例題**　一個 $4$ 公分 $\times$ $6$ 公分的長方形標誌，要等比例放大到寬 $10$ 公分。放大後的長是多少？面積變成原來的幾倍？

相似比是 $\frac{10}{4}=2.5$，長變成 $6\times 2.5=15$ 公分。面積比是 $2.5^2=6.25$：原來 $24$ 平方公分，放大後 $10\times 15=150$ 平方公分，$150\div 24=6.25$，兩種算法一致。

<Graph desc="原來 4×6 的長方形（橘色）和等比例放大 k 倍的長方形 4k×6k（藍色），左下角都在原點。拉動 k：寬是 4k、長是 6k，面積是 24k²；k=2 時大長方形剛好由 4 個原來的長方形拼成，k=2.5 時放大成 10×15，面積 150，是原來的 6.25 倍。" x={[-1, 16]} y={[-1, 16]}
  params={[{ name: 'k', min: 0.5, max: 2.5, step: 0.25, value: 2.5 }]}
  polygons={[{ points: [[0, 0], [4, 0], [4, 6], [0, 6]] }, { points: [[0, 0], ['4*k', 0], ['4*k', '6*k'], [0, '6*k']], color: 'blue' }]}
  points={[{ at: ['4*k', '6*k'], label: '(4k, 6k)', color: 'blue' }]} />

<Perspective title="分兩步伸縮：面積為什麼乘 k²">

把放大拆成兩步。先只把寬放大 $2.5$ 倍、長不變：$4\times 6$ 變成 $10\times 6$，面積 $24\to 60$，乘了 $2.5$。再只把長放大 $2.5$ 倍：$10\times 6$ 變成 $10\times 15$，面積 $60\to 150$，又乘了 $2.5$。兩步合起來就是 $2.5\times 2.5=6.25$ 倍。

第一步之後的 $10\times 6$ 和原圖**不相似**（寬長比從 $2:3$ 變成 $5:3$），面積只乘 $k$；兩個方向都放大才相似，面積才乘 $k^2$。對任何形狀也成立：把圖形想成由許多小方格拼成，每個 $1\times 1$ 的小方格放大後都變成 $k\times k$，面積是 $k^2$，所以三角形、圓放大 $k$ 倍，面積同樣變成 $k^2$ 倍。

</Perspective>

### 生活情境：路燈下的影子

**例題**　路燈高 $4.5$ 公尺，身高 $1.5$ 公尺的人站在離燈柱 $4$ 公尺處。他的影子有多長？

設影子長 $s$ 公尺。燈頂、燈柱底、影子末端圍成大直角三角形，人和自己的影子圍成小直角三角形，兩者共用影子末端的角，所以相似：

$$
\frac{1.5}{4.5}=\frac{s}{4+s}\implies 3s=4+s\implies s=2
$$

<Graph desc="路燈的燈柱在 x=0，燈頂 (0, 4.5)；身高 1.5 的人站在離燈柱 d 處，頭頂在 (d, 1.5)。虛線是經過燈頂與頭頂的光線，它碰到地面的點 (1.5d, 0) 就是影子末端，紅色線段是影子，長 d/2。拉動 d：人走得越遠，影子越長，而且影子永遠是距離的一半；d=4 時影子長 2。" x={[-1, 13]} y={[-0.5, 5.5]}
  params={[{ name: 'd', min: 1, max: 8, step: 0.5, value: 4 }]}
  segments={[{ from: [0, 0], to: [0, 4.5] }, { from: ['d', 0], to: ['d', 1.5], color: 'blue' }, { from: [0, 4.5], to: ['1.5*d', 0], color: 'amber', dashed: true }, { from: ['d', 0], to: ['1.5*d', 0], color: 'red' }]}
  points={[{ at: [0, 4.5], label: '燈頂' }, { at: ['d', 1.5], label: '頭頂', color: 'blue' }, { at: ['1.5*d', 0], label: '影子末端', color: 'red' }]} />

<Perspective title="用直線方程式：光線碰到地面的地方">

把燈柱底放在原點、地面當 $x$ 軸。光線經過燈頂 $(0,\,4.5)$ 和頭頂 $(4,\,1.5)$，斜率是 $\frac{1.5-4.5}{4-0}=-\frac{3}{4}$，所以光線是

$$
y=-\tfrac{3}{4}x+4.5
$$

令 $y=0$，得 $x=6$：影子末端在 $(6,0)$，影子長 $6-4=2$ 公尺，和相似三角形的答案一樣。

一般地，人站在 $(d,0)$，光線斜率 $\frac{1.5-4.5}{d}=-\frac{3}{d}$，$y=-\frac{3}{d}x+4.5$ 碰到地面在 $x=1.5d$，影子長 $1.5d-d=\frac{d}{2}$。用相似三角形看也一樣：人高是燈高的 $\frac{1}{3}$，所以影子是「燈柱到影子末端」整段的 $\frac{1}{3}$，也就是距離 $d$ 的一半。

</Perspective>

<StudentAsks q="放大 2 倍，面積為什麼不是 2 倍？">

因為長和寬**都**放大了 $2$ 倍，面積就放大 $2\times 2=4$ 倍。同樣的道理，相似比是 $k$ 的兩個圖形，周長比是 $k$，面積比是 $k^2$。

</StudentAsks>

## 單點透視：平行線交於消失點

畫透視圖，可以想成眼睛固定在一點，從眼睛看出去的每一條視線穿過一張直立的畫紙，穿過的位置就是那個點在畫上的位置。**單點透視**是指畫紙和物體的正面平行，這時有幾條規則：

1. 直線畫出來仍然是直線；兩條線的交點，畫出來仍是交點。
2. 和畫紙平行的線（例如物體正面的水平邊、鉛直邊），畫出來方向不變：這種線若真實中互相平行，畫出來仍然互相平行；這種線段若在同一個深度、真實中又等長，畫出來也等長。
3. 和畫紙垂直、往遠方延伸的平行線（例如鐵軌、走廊兩側的牆腳），畫出來會交於同一點，這個點叫做**消失點**。消失點在和眼睛同高的水平線上，這條線叫做**地平線**。
4. 越遠的東西畫得越小：真實高度 $h$、深度 $d$（從眼睛沿著垂直畫紙的方向量）的物體，畫出來的高度是 $\frac{f\,h}{d}$，其中 $f$ 是眼睛到畫紙的距離。這又是一對相似三角形。

所以往遠方延伸的線上，真實中等長的段落，畫出來會越來越短。透視圖裡的長度不能直接量，但「直線」和「交點」可以放心用。

把眼睛放在 $E(0,0,2)$（離地 $2$），往 $+y$ 方向看，畫紙是平面 $y=1$（$f=1$）。地上有兩條鐵軌 $x=1$ 與 $x=-1$（$z=0$），$y$ 越大越遠。鐵軌上一點 $P(a,d,0)$ 畫在畫紙上的哪裡？分兩個方向看，各是一對相似三角形。從正上方看（只看 $x$、$y$）：眼睛在 $(0,0)$、$P$ 在 $(a,d)$，視線往前走 $d$ 時橫向移動 $a$，走到畫紙 $y=1$ 只往前走了 $1$，所以橫坐標是 $\frac{a}{d}$。從側面看（只看 $y$、$z$）：視線從高度 $2$ 往前走 $d$ 才降到地面，走到畫紙只往前走了 $1$，所以只降了 $\frac{2}{d}$，高度是 $2-\frac{2}{d}$。所以 $P$ 畫在

$$

$$

- 右軌 $a=1$：$d=1,2,4$ 分別畫在 $(1,1,0)$、$(0.5,1,1)$、$(0.25,1,1.5)$。畫紙上的橫坐標 $\frac{a}{d}$ 正是規則 4 的 $\frac{f\,h}{d}$（$f=1$、$h=a$）。真實中從 $d=1$ 到 $d=2$（長 $1$），畫上升高 $1$；從 $d=2$ 到 $d=4$（長 $2$），畫上只升高 $0.5$：越遠畫得越短。
- 這些點都滿足 $z=2-2x$，畫出來確實是一條直線（規則 1）。
- $d$ 越大，$\frac{a}{d}$ 越接近 $0$、$2-\frac{2}{d}$ 越接近 $2$：**不管 $a$ 是多少**，左軌、右軌或任何一條和它們平行的線，畫出來都朝同一點 $V(0,1,2)$ 靠近，這就是消失點（規則 3）。它的高度 $2$ 正是眼睛的高度，所以消失點在地平線上。

### 用直線方程式找消失點

**例題**　一張走廊地板的單點透視圖放在坐標平面上。地板左邊的牆腳經過 $(0,0)$ 與 $(2,3)$，右邊的牆腳經過 $(8,0)$ 與 $(6,3)$。求消失點。

兩條牆腳在真實中平行、往遠方延伸，所以消失點就是它們在畫上的交點。左牆腳的<Term t="math.slope">斜率</Term>是 $\frac{3}{2}$，直線為 $y=\frac{3}{2}x$；右牆腳斜率 $\frac{3-0}{6-8}=-\frac{3}{2}$，用<Term t="math.point-slope-form">點斜式</Term>得 $y=-\frac{3}{2}(x-8)$。聯立：

$$
\tfrac{3}{2}x=-\tfrac{3}{2}x+12\implies x=4,\ y=6
$$

消失點是 $(4,6)$，地平線是 $y=6$。在 $y=3$ 這一排，地板畫出來的寬是 $6-2=4$，只有最前排寬 $8$ 的一半；由規則 4（和畫紙平行的寬度也一樣，和深度成反比），那一排離眼睛的距離是最前排的 $2$ 倍。

<Graph desc="走廊地板的透視圖：左牆腳 y=3x/2、右牆腳 y=−3(x−8)/2，交於消失點 (4, 6)，虛線是地平線 y=6。黑色虛線是真實中等距的幾排地板：最前排在 y=0（寬 8），深度 2 倍的一排在 y=3（寬 4），3 倍在 y=4，4 倍在 y=4.5，越遠排得越密。拉動 n（這一排的深度是最前排的 n 倍）：由規則 4，紅線畫在 y=6−6/n，寬 8/n，n 越大越靠近消失點。" x={[-1, 9]} y={[-1, 7]}

<Perspective title="不解聯立：用平行線截比例線段找消失點">

設消失點是 $V$。$V$、$(0,0)$、$(8,0)$ 圍成一個三角形，$(2,3)$ 在左邊上、$(6,3)$ 在右邊上，而連接 $(2,3)$、$(6,3)$ 的線段是水平的，和底邊平行。由平行線截比例線段：

$$
\frac{V\text{ 到 }(2,3)\text{ 的距離}}{V\text{ 到 }(0,0)\text{ 的距離}}=\frac{6-2}{8-0}=\frac{1}{2}
$$

所以 $(2,3)$ 是 $V$ 與 $(0,0)$ 的中點，$V=2(2,3)-(0,0)=(4,6)$，和解聯立的結果相同。換個說法：地板的寬度隨高度均勻縮小，每往上 $3$ 寬度少 $4$，寬 $8$ 要往上 $6$ 才縮到 $0$，所以消失點的高度是 $6$。

</Perspective>

### 透視圖中真正的一半

**例題**　承上題，$A(0,0)$、$B(8,0)$、$C(6,3)$、$D(2,3)$ 是一塊長方形地磚的透視圖。要畫出把地磚前後平分的那條線，應該畫在哪裡？

真實的長方形中，兩條對角線交於中心，過中心且和前緣平行的線把它前後平分。由規則 1，對角線的交點畫出來仍是交點；由規則 2，和前緣平行的線畫出來仍是水平線。$\overline{AC}$：$y=\frac{1}{2}x$；$\overline{BD}$：斜率 $\frac{3-0}{2-8}=-\frac{1}{2}$，$y=-\frac{1}{2}(x-8)$。聯立得 $x=4$、$y=2$。

所以平分線畫在 $y=2$，不是 $y=\frac{0+3}{2}=1.5$：近的那一半在畫面上佔 $2$ 單位高，遠的那一半只佔 $1$ 單位。

<Perspective title="用深度算：畫在地平線下多遠，和深度成反比">

由規則 4，地板上一點畫在地平線下方的距離，和它的深度成反比（眼睛高度固定，就像 $\frac{f\,h}{d}$ 裡的 $h$ 固定）。地平線是 $y=6$：前緣 $\overline{AB}$ 畫在下方 $6$，後緣 $\overline{DC}$ 畫在下方 $3$，所以後緣的深度是前緣的 $2$ 倍。設前緣深度 $d_0$，後緣就是 $2d_0$。

真實的一半在深度 $\frac{d_0+2d_0}{2}=1.5d_0$，畫在地平線下方

$$
6\times\frac{d_0}{1.5d_0}=4
$$

也就是 $y=6-4=2$，和對角線法的答案相同。這也說明了為什麼不是 $1.5$：畫面上的高度和 $\frac{1}{\text{深度}}$ 成正比，不是和深度成正比，所以真實的等分畫出來不會等分。下面「動手試試」的答案，也可以用這個方法驗算。

<StudentAsks q="對角線的交點 (4, 2) 也是兩條線的交點，它為什麼不是消失點？">

消失點只來自**真實中互相平行、往遠方延伸**的那一組線。兩條對角線在真實中並不平行，它們本來就相交在地磚中心，畫出來的交點只是那個中心的位置。找消失點時，要先確認用的是哪一組平行線，而且只能用題目保證的性質，不能憑圖「看起來」對稱或等長就下結論。

</StudentAsks>
