## 混合題組與評分原則

依111–115學年度的試卷（116學年度的版面尚未確認），數A與數B的第貳部分都是一組混合題組，共 $15$ 分，分成 $3$ 個小題；各小題的配分和題型逐年不同。例如115學年度數A的題組是第 $18$ 題單選 $3$ 分、第 $19$ 題非選 $4$ 分、第 $20$ 題非選 $8$ 分。所以混合題組裡也可能有選擇題；這一章專講要寫過程的非選擇小題。

大考中心在115學年度數A的非選擇題評分原則裡這樣說明：

| 你的作答 | 結果 |
|---|---|
| 推理正確、過程詳細，而且答案正確 | 滿分 |
| 推理正確，但沒有得到最後答案 | 酌給部分分數 |
| 沒寫過程、推論錯誤，或用了與題意矛盾的數據 | 零分 |

數B的說明也一樣要求寫出計算過程或理由、依推理過程評分，沒寫過程或推論錯誤者以零分計。換句話說，只寫一個正確答案不夠；一步錯誤的推論，也可能讓整題拿不到分數。

<OnTheExam item="115-mathA-q18-20">

打開「評分原則」，看第 $19$ 題的分數怎麼拆：正確找出法向量就能拿到部分分數。也就是說，中間每一個寫對、寫清楚的步驟都有價值。

</OnTheExam>

## 一份完整的作答：前提、理由、結論

寫非選擇題時，用這四個習慣檢查自己的作答：

1. **寫出前提**：設了什麼未知數、用了題目的哪一個條件（例如 $x>0$）。
2. **每一步附上理由**：用到的定理、公式或性質要寫出來，例如「由算幾不等式」、「因為 $y=2^x$ 嚴格遞增」。
3. **讓每一步都能檢查**：除以一個式子之前說明它不為 $0$，兩邊平方之後要驗根。
4. **寫出結論**：回答題目問的東西，連同等號成立的條件或範圍。

**例題**　已知 $x>0$，求 $x+\frac{9}{x}$ 的最小值。

先看一份不完整的作答：

> $x=3$ 時，$3+\frac{9}{3}=6$，所以最小值是 $6$。

數字是對的，但這只是試了一個值，沒有說明為什麼其他的 $x$ 不會更小，推理並不成立。完整的寫法是：

> 因為 $x>0$，所以 $x$ 與 $\frac{9}{x}$ 都是正數。由<Term t="math.am-gm-inequality">算幾不等式</Term>，
> $x+\frac{9}{x}\ge 2\sqrt{x\cdot\frac{9}{x}}=2\sqrt{9}=6$。
> 等號成立的條件是 $x=\frac{9}{x}$，即 $x^2=9$，又 $x>0$，所以 $x=3$。
> 因此 $x+\frac{9}{x}$ 的最小值為 $6$，在 $x=3$ 時取得。

這份作答四個習慣都做到了：前提（$x>0$，兩數為正）、理由（算幾不等式）、可檢查的等號條件，以及結論。

「最小值是 $6$」也可以在圖上看：水平線 $y=c$ 要碰得到曲線 $y=x+\frac{9}{x}$（$x>0$），$c$ 至少要是 $6$。拉動 $c$ 看看。

<Graph desc="曲線是 y=x+9/x（x>0），最低點是 (3,6)。虛線是水平線 y=c，隨滑桿 c 上下移動：一開始 c=8，和曲線交於兩點；c=6 時恰好在 (3,6) 碰到曲線；c<6 時完全碰不到。所以 x+9/x 能取到的最小值是 6。" x={[0, 10]} y={[0, 14]}
  params={[{ name: 'c', min: 2, max: 12, step: 0.5, value: 8 }]}
  functions={[{ expr: 'x+9/x', domain: [0.6, 10], label: 'y=x+9/x' }, { expr: 'c', color: 'amber', dashed: true, label: 'y=c' }]}
  points={[{ at: [3, 6], label: '(3, 6)' }]} />

<Perspective title="不用算幾：湊成完全平方">

因為 $x>0$，可以把「和減去 $6$」寫成一個分式：

$$
x+\frac{9}{x}-6=\frac{x^2-6x+9}{x}=\frac{(x-3)^2}{x}
$$

分子 $(x-3)^2\ge 0$，分母 $x>0$，所以這個差不小於 $0$，即 $x+\frac{9}{x}\ge 6$；等號成立若且唯若 $(x-3)^2=0$，即 $x=3$。因此最小值為 $6$，在 $x=3$ 時取得。

這份作答一樣有前提（$x>0$，才能確定分母為正）、理由（平方不小於 $0$）、等號條件和結論，只是不必引用算幾不等式。

</Perspective>

<Perspective title="用判別式：水平線什麼時候碰得到曲線">

把圖上的問題翻成方程式：$x+\frac{9}{x}=c$ 有沒有正數解？因為 $x>0$，所以 $x\ne 0$，兩邊同乘以 $x$ 不會改變解，得 $x^2-cx+9=0$。

- 要有實數解，判別式 $c^2-36\ge 0$，即 $c\ge 6$ 或 $c\le -6$。
- $x>0$ 時 $c=x+\frac{9}{x}>0$，所以 $c\le -6$ 不可能，只剩 $c\ge 6$。
- 反過來，$c\ge 6$ 時兩根之積是 $9>0$、兩根之和是 $c>0$，兩根都是正數，所以確實有正數解。

因此 $x+\frac{9}{x}$ 能取到的值正好是 $c\ge 6$，最小值是 $6$；$c=6$ 時 $x^2-6x+9=(x-3)^2=0$，$x=3$，就是圖上虛線碰到曲線的那一點。注意第一步同乘以 $x$ 之前，先寫了 $x\ne 0$：這正是「讓每一步都能檢查」。

</Perspective>

<StudentAsks q="要寫多詳細？每一個加減都要寫出來嗎？">

不用把每一個加減都寫出來。重要的是推理的關鍵步驟都看得到：用了什麼條件、引用了什麼性質、為什麼這一步可以這樣做。評分原則要的是「推理正確、過程詳細」，所以寧可多寫一句理由，也不要跳過關鍵的一步。

</StudentAsks>

## 最容易失分的步驟

很多失分不是算錯，而是某一步少了前提，推論就不成立：

| 步驟 | 可能出的問題 | 要補上的 |
|---|---|---|
| 兩邊同除以一個式子 | 那個式子可能是 $0$ | 先說明它不為 $0$，或把它是 $0$ 的情況另外討論 |
| 兩邊平方 | 可能多出原方程式沒有的解 | 把每一個候選解代回原方程式檢驗 |
| 約分 | 分母可能是 $0$ | 先寫出分母不為 $0$ 的條件 |
| 比較兩個函數值 | 只寫結果，沒有理由 | 引用函數在那個範圍內遞增或遞減 |

回到開頭的 $x^2=3x$：方程式的實數解，就是拋物線 $y=x^2$ 和直線 $y=3x$ 交點的 $x$ 坐標。圖上有兩個交點，所以有兩個解；兩邊同除以 $x$ 之後只剩一個，少掉的正是 $x=0$ 那一點。

<Graph desc="拋物線 y=x² 與直線 y=3x 交於兩點 (0,0) 與 (3,9)，所以 x²=3x 有兩個實數解 x=0 與 x=3。兩邊同除以 x 只留下 (3,9)，原點那個交點就不見了。" x={[-2, 5]} y={[-2, 12]}

**例題**　解方程式 $\sqrt{x+2}=x$。

兩邊平方得 $x+2=x^2$，即 $x^2-x-2=(x-2)(x+1)=0$，候選解為 $x=2$ 或 $x=-1$。平方可能產生不合的解，所以代回原方程式檢驗：

- $x=2$：左邊 $\sqrt{4}=2$，右邊 $2$，成立。
- $x=-1$：左邊 $\sqrt{1}=1$，右邊 $-1$，不相等，不合。

所以方程式的解為 $x=2$。注意寫「$x=-1$ 不合」時，也要寫出它為什麼不合。

在圖上看，就知道 $x=-1$ 從哪裡來：兩邊平方以後，$x+2=x^2$ 分不出原來是 $\sqrt{x+2}=x$ 還是 $-\sqrt{x+2}=x$，所以下半條曲線的交點也跑進來了。

<Graph desc="實線 y=√(x+2) 是從 (−2,0) 往右上升的半條曲線，它和直線 y=x 只交於 (2,2)。虛線 y=−√(x+2) 是下半條，和 y=x 交於 (−1,−1)。兩邊平方後的 x+2=x² 把上下兩半都算進去，所以多出 x=−1；原方程式只有實線那一半，解只有 x=2。" x={[-3, 5]} y={[-3, 4]}
  functions={[{ expr: 'sqrt(x+2)', domain: [-2, 5], label: 'y=√(x+2)' }, { expr: '-sqrt(x+2)', domain: [-2, 5], color: 'amber', dashed: true, label: 'y=−√(x+2)' }, { expr: 'x', color: 'ink', label: 'y=x' }]}
  points={[{ at: [2, 2], label: '(2, 2)' }, { at: [-1, -1], label: '(−1, −1)', color: 'amber' }]} />

<Perspective title="先看正負，就不必事後驗根">

右邊的 $x$ 等於一個根號，而根號的值不小於 $0$，所以先得到條件 $x\ge 0$。在 $x\ge 0$ 的前提下，兩邊都不是負數；兩個非負數相等，若且唯若它們的平方相等，所以平方不會多出解：

$$
\sqrt{x+2}=x \iff x+2=x^2\ \text{且}\ x\ge 0
$$

（$x+2=x^2\ge 0$ 也保證了根號有意義。）解 $x^2-x-2=0$ 得 $x=2$ 或 $x=-1$，只有 $x=2$ 落在 $x\ge 0$ 的範圍內。

<NumberLine desc="數線上 x≥0 的部分塗色，0 是實心點。候選解 −1 在塗色範圍外，不合；2 在範圍內，是解。" from={-3} to={4} intervals={[{ a: 0, b: 'inf', open: [false, false] }]} points={[{ x: -1, label: '−1', open: true }, { x: 2, label: '2' }]} />

這個寫法把驗根提前到平方之前：先寫出條件 $x\ge 0$ 和理由（根號的值非負），再平方。在答案卷上，事後驗根和事先寫條件都是完整的作答，選一種寫清楚就好。

</Perspective>

## 做不完，也要把推理寫下來

就算某一小題做不完，正確的設定和推理也值得寫下來，因為評分原則對「推理正確但沒有得到最後答案」的作答酌給部分分數。

**例題（自擬題組）**　用長 $40$ 公尺的籬笆，靠著一面很長的牆圍出一個長方形花圃，靠牆的那一邊不用籬笆。設垂直於牆的邊長為 $x$ 公尺。

先把圖畫對：牆在下面，籬笆只圍另外三邊，兩段垂直於牆、一段平行於牆。拉動 $x$，看兩個邊長怎麼一起變。

<Graph desc="靠牆的長方形花圃：x 軸上那條水平線是牆，另外三邊是籬笆。滑桿 x 是垂直於牆的邊長，平行於牆的邊長是 40−2x，三段籬笆加起來永遠是 x+(40−2x)+x=40。一開始 x=6，平行於牆的邊長 28，面積 168；x 越靠近 0 或 20，長方形越扁，面積都越接近 0。" x={[-4, 43]} y={[-4, 23]} height={260}

  segments={[{ from: [-4, 0], to: [43, 0], color: 'ink' }, { from: [0, 0], to: [0, 's'], color: 'red' }, { from: [0, 's'], to: ['40-2*s', 's'], color: 'red' }, { from: ['40-2*s', 's'], to: ['40-2*s', 0], color: 'red' }]}

1. 平行於牆的邊長是 $40-2x$ 公尺，所以花圃面積 $A=x(40-2x)$ 平方公尺。
2. 兩邊長都要是正數：$x>0$ 且 $40-2x>0$，所以 $0<x<20$。
3. 求花圃面積的最大值，並說明理由。

第 $3$ 小題的完整寫法：$A=-2x^2+40x$ 是開口向下的<Term t="math.quadratic-function">二次函數</Term>。用<Term t="math.completing-the-square">配方法</Term>，

$$
A=-2(x^2-20x)=-2(x-10)^2+200
$$

所以 $A\le 200$，等號成立於 $x=10$；而 $x=10$ 在範圍 $0<x<20$ 內，所以面積的最大值是 $200$ 平方公尺，此時垂直於牆的邊長 $10$ 公尺、平行於牆的邊長 $20$ 公尺。

把 $A$ 對 $x$ 畫出來，配方的結果就是圖上的最高點：

<Perspective title="用對稱：兩個零點的正中間">

$A=x(40-2x)$ 在 $x=0$ 與 $x=20$ 時都是 $0$，也就是圖上和橫軸的兩個交點。拋物線對稱於對稱軸，這兩點等高，所以對稱軸在它們正中間：$x=\frac{0+20}{2}=10$。開口向下，頂點最高，$A(10)=10\times 20=200$。

作答時寫出「$x=0$ 與 $x=20$ 是 $A=0$ 的兩根，拋物線對稱於兩根的中點 $x=10$，開口向下，所以 $x=10$ 時 $A$ 最大」，一樣是完整的理由，不必配方；最後同樣要檢查 $x=10$ 在 $0<x<20$ 內。

</Perspective>

<Perspective title="用算幾不等式：兩段的和固定">

因為 $0<x<20$，$2x$ 與 $40-2x$ 都是正數，而且兩者的和固定：$2x+(40-2x)=40$。由算幾不等式，

$$
\sqrt{2x(40-2x)}\le\frac{2x+(40-2x)}{2}=20
$$

所以 $2x(40-2x)\le 400$，$A=x(40-2x)=\frac{1}{2}\cdot 2x(40-2x)\le 200$。等號成立於 $2x=40-2x$，即 $x=10$，在範圍內，所以最大面積是 $200$ 平方公尺。

這和本章第一個例題是同一個工具：兩個正數的積固定時，和有最小值；和固定時，積有最大值。為什麼拆成 $2x$ 與 $40-2x$，而不是 $x$ 與 $40-2x$？因為 $x+(40-2x)=40-x$ 不是定值，算幾不等式給出的上界會跟著 $x$ 變，推不出最大值。

</Perspective>

如果配方卡住了，還是可以寫下第 $1$、$2$ 小題的式子與範圍，以及「$A$ 是開口向下的二次函數，最大值在頂點」這樣正確的推理。最後也別忘了檢查頂點的 $x$ 是否落在範圍內：這正是「每一步都能檢查」的一部分。
