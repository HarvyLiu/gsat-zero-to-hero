```dialogue
S：情境是什麼？

T：先猜一題，這是化學的觀念。
T：汽水回溫的時候，二氧化碳在汽水裡的溶解度會怎樣？
>> turn: q-turn
S：我以為溫度越高溶得越多，像糖一樣……可是汽水放到不冰，冒的泡反而比較多。所以氣體是反過來的：溫度越高，溶解度越小。
T：對，溶解度變小。大多數固體是溫度越高溶得越多，氣體卻相反。記住這個觀念，等一下要用數據檢驗：汽水冒泡，真的主要是因為回溫嗎？
```

這是116衝刺的重點複習：假設你在學校上過自然科學探究與實作，也讀完了必修的物理、化學、生物、地球科學。本章不教新的學科內容，只用各科複習過的觀念，每用到一個，就附上那一章的連結。

## 一、先拆題組：每一小題要哪一科、哪一種能力

依大考中心的說明，混合題是一個題組，一般有2到4小題，由選擇題開始，再到非選擇題。112到115學年度，每年第貳部分都有兩科合出的跨科題組。例如113學年度第40–43題是物理與生物，其中第43題直接考變因與預測結果，第50–53題是化學與地科；115學年度第貳部分的6個題組中，第40–43題（生物與化學）和第50–53題（地科與物理）是跨科題組。同一個跨科題組裡，每一小題仍各有歸屬：115學年度的非選擇題，第50題算地科，第53題算物理。

考試說明的試題舉例，除了標出學科的學習內容，也標出探究與實作的項目，例如「論證與建模－解釋和推理」；外傘頂洲題組的第1題，甚至只標探究與實作的項目。所以拿到題組，先替每一小題標兩件事：**要用哪一科的觀念**、**考哪一種探究能力**。

下面是本章的原創題組（示意數據）。某生從冰箱取出一瓶汽水，打開瓶蓋，放在室溫24℃的桌上。每10分鐘量一次汽水的溫度，並用讀到0.1 g的電子秤秤整瓶的質量（每次秤之前，先擦乾瓶外凝結的水珠）。

1. 汽水的溫度越升越慢，最後停在約24℃。說明原因。
2. 由數據算出前30分鐘逃出的二氧化碳質量。
3. 建立一個模型，描述升溫和逃出的二氧化碳有什麼關係，並說出它的範圍。
4. 某生主張：「汽水回溫，使二氧化碳的溶解度變小，所以氣體跑出來。」評價這個主張，並提出改進的實驗設計。（非選擇題）

| 小題 | 學科觀念 | 探究能力 |
|---|---|---|
| 1 | 物理：熱由高溫流向低溫 | 論證與建模－解釋和推理 |
| 2 | 化學：開放容器中氣體逃出，讀數變小 | 論證與建模－分析資料和呈現證據 |
| 3 | 物理＋化學：升溫對逃出的氣體 | 論證與建模－建立模型 |
| 4 | 化學：氣體的溶解度隨溫度升高而變小 | 表達與分享－評價與省思 |

1. **題目的動詞決定能力**：「說明原因」是解釋和推理；「算出」是分析資料；「建立模型」是建立模型；「評價」「提出改進」是評價與省思，加上擬定研究計畫。

兩條線索標出來的結果和表格一致。如果欄位看起來屬於一科、題目問的卻是另一科（例如用溫度那一欄問溶解度），以題目問的為準。

再看質量。60分鐘內，電子秤的讀數一共減少了 $3.6\ \mathrm{g}$。

```dialogue
S：瓶蓋打開了，二氧化碳跑出去，讀數就變小。所以減少的3.6公克，就是逃出的二氧化碳。

>> turn: q-control

```

| 時間（min） | 汽水減少（g） | 清水減少（g） |
|---|---|---|
| 0 | 0 | 0 |
| 10 | 1.3 | 0.1 |
| 20 | 2.2 | 0.2 |
| 30 | 2.7 | 0.3 |
| 40 | 3.1 | 0.4 |
| 50 | 3.4 | 0.5 |
| 60 | 3.6 | 0.6 |

這是<Term t="chemistry.conservation-of-mass">質量守恆定律</Term>在開放容器裡的樣子：總質量沒有少，只是氣體和水蒸氣離開了瓶子，秤不到而已（[化學基本定律與原子說](/zh-tw/chemistry/s116-laws-atomic-theory/)）。第2小題的答案，是把清水蒸發的部分扣掉：

$$
2.7-0.3=2.4\ \mathrm{g}
$$

前30分鐘逃出的二氧化碳約 $2.4\ \mathrm{g}$。答案要帶單位，也要寫出這個相減，因為它就是你的證據。

<StudentAsks q="為什麼不直接量二氧化碳，要繞一圈去秤質量？">

逃出的二氧化碳散進教室的空氣裡，很難收集起來量。質量卻很好量，電子秤一放就有讀數。只要用對照組扣掉水的蒸發，剩下的就是二氧化碳。證據常常是這樣：量一個量得到的量，再用設計好的比較，把它換成你真正想知道的量。

</StudentAsks>

## 三、建立跨科的模型，找出它的極限

第3小題要把兩科接起來：一邊是物理的升溫，一邊是化學的逃出氣體。把每10分鐘的變化並排：

| 時段（min） | 升溫（℃） | 逃出CO₂（g） |
|---|---|---|
| 0→10 | 8 | 1.2 |
| 10→20 | 5 | 0.8 |
| 20→30 | 3 | 0.4 |
| 30→40 | 2 | 0.3 |
| 40→50 | 1 | 0.2 |
| 50→60 | 0 | 0.1 |

逃出的二氧化碳＝汽水減少的量－清水減少的量，例如0→10是 $1.3-0.1=1.2\ \mathrm{g}$。升溫多的時段，逃出的也多。用前30分鐘建立一個模型：

$$
\frac{1.2+0.8+0.4}{8+5+3}=\frac{2.4}{16}=0.15\ \mathrm{g/{}^{\circ}C}
$$

模型：**每升溫1℃，約逃出0.15 g二氧化碳**。它看起來正好符合「回溫使溶解度變小」。

## 四、評價主張：證據夠不夠，有沒有對立解釋

回到第4小題的主張：「汽水回溫，使二氧化碳的<Term t="chemistry.solubility">溶解度</Term>變小，所以氣體跑出來。」

它用的化學觀念是對的：溫度越高，氣體在水中的溶解度越小（[溶液、濃度與溶解度](/zh-tw/chemistry/s116-solutions/)）。但評價主張，要問的是**這組數據能不能支持它、支持到什麼程度**。

讀圖：在桌上那瓶的數據裡，兩支箭頭同時存在，分不開。冷水浴那瓶拿掉了哪一支？拿掉了藍色的「回溫」：它沒有升溫，逃出的 $2.0\ \mathrm{g}$ 只能算給「開瓶後」。

<StudentAsks q="氣體的溶解度隨溫度升高而變小，是課本寫的。那這個主張不就一定對嗎？">

觀念對，不等於它能解釋這一次看到的現象。主張說「所以氣體跑出來」，好像回溫是全部的原因。數據卻顯示：不回溫也會逃出 $2.0\ \mathrm{g}$，回溫只讓它多了約 $1.0\ \mathrm{g}$。評價主張，要拿數據去量這個觀念在這裡占了多少。

</StudentAsks>

<Perspective title="兩種評價：看證據，也看對立解釋">

這是[論證與建模](/zh-tw/inquiry/s116-inq-argue-model/)那一章的兩種檢查，這裡用在跨科題組的主張上。

**第一種：看證據。** 主張預測「升溫多的時段，逃出得多」，桌上那瓶的數據符合；但這組數據的範圍只有一瓶汽水、一次實驗。

**第二種：看對立解釋。** 對立的說法是「打開瓶蓋本身，就會讓氣體跑出來」。它預測：就算不回溫，氣體也會逃出，而且一打開時逃得最快。冷水浴那瓶正好符合它。

把兩者放在一起，數據支持的結論是：「在這次實驗中，60分鐘內，泡在冷水浴的那瓶逃出 $2.0\ \mathrm{g}$，放在桌上的逃出 $3.0\ \mathrm{g}$；回溫使逃出的二氧化碳多了約 $1.0\ \mathrm{g}$，但大部分的氣體在不回溫時也會逃出。」

要讓結論更可信，還可以改進：

1. 每一組各做三瓶，看結果是否重複出現。
2. 多加一組溫度，例如泡在15℃的水裡，看逃出的量是不是隨溫度穩定地增加。
3. <Term t="inquiry.manipulated-variable">操縱變因</Term>是汽水保持的溫度（℃），<Term t="inquiry.responding-variable">應變變因</Term>是60分鐘內逃出的二氧化碳（g），<Term t="inquiry.controlled-variable">控制變因</Term>是同一種汽水、同樣的量、同時打開、秤前擦乾水珠。

</Perspective>

## 五、寫出跨科的推理

學測第貳部分的非選擇題，要寫出計算過程或理由，否則會被扣分。物理的「[因次檢查與非選擇題的推理寫法](/zh-tw/physics/s116-physics-reasoning/)」一章也提到：113學年度第43題的評分原則，要求變因寫成可以測量的量。跨科的非選題，可以照[論證與建模](/zh-tw/inquiry/s116-inq-argue-model/)那一章結論的四個部分來寫，只是把「範圍」寫成資料的「限制」，排成四個方框：

第4小題的示範答案：

- **主張**：這個主張只說對了一部分。
- **證據**：泡在5℃冷水浴的那瓶，60分鐘內也逃出 $2.0\ \mathrm{g}$；放在桌上、回溫到24℃的那瓶逃出 $3.0\ \mathrm{g}$。
- **推理**：溫度越高，氣體的溶解度越小（化學），所以回溫多出了約 $1.0\ \mathrm{g}$；但不回溫也逃出 $2.0\ \mathrm{g}$，大部分是開瓶本身造成的。桌上那瓶的回溫，來自熱由較熱的空氣流向較冷的汽水（物理）。
- **限制與改進**：每組只有一瓶；每組各做三瓶，並加一組15℃。
