這是116衝刺的重點複習：假設你在學校上過自然科學探究與實作，也讀完了必修的物理、化學、生物、地球科學。116學測自然考科的範圍是必修物理、化學、生物、地球科學（含探究與實作），四科以占分比例相當為原則。本章不教新的學科內容，只把各科複習過的觀念拿來用，每用到一個，就附上那一章的連結。

## 一、四科各問一個可以驗證的問題

課綱的自然科學探究與實作是跨科、以主題或議題帶動的課程，並列出七個<Term t="inquiry.cross-cutting-concepts">跨科概念</Term>：物質與能量、構造與功能、系統與尺度、改變與穩定、交互作用、科學與生活、資源與永續性。它們不專屬於哪一科，所以很適合當提問的角度。本章主要用其中四個。

先從四個觀察開始，讓每一科各問一題。可以驗證的問題要說得出**改變什麼、測量什麼**，而且都量得到：

| 觀察 | 哪一科 | 可以驗證的問題 |
|---|---|---|
| 細樹枝比粗木柴容易點著 | 化學 | 同樣質量的木柴，劈得越細，燒完的時間是否越短？ |
| 坐得越近越暖 | 物理 | 離火越遠，溫度計的讀數是否越低？ |
| 木柴來自樹 | 生物 | 同一種樹苗，每天照光越久，一個月後增加的乾重是否越多？ |
| 煙把碳帶進夜空 | 地科 | 木柴和煤這兩種燃料裡的碳，各是多久以前離開大氣的？ |

每一題都說得出要改變或比較的量，和要測量的量：

| 科目 | 改變或比較的量 | 測量的量 |
|---|---|---|
| 化學 | 每塊木柴的大小 | 燒完的時間（min） |
| 物理 | 與火的距離（m） | 溫度（℃） |
| 生物 | 每天照光的時數（h） | 增加的乾重（g） |
| 地科 | 燃料的種類 | 碳離開大氣到現在的時間（年，查資料） |

地科這一題不靠做實驗，而是靠蒐集資料來回答：比較兩種燃料，說得出要查的量是時間（年），就能用資料來驗證。

<StudentAsks q="直接問「營火是怎麼回事？」不行嗎？為什麼一定要寫出測量什麼？">

這個問題太大，你不知道該從哪裡量起，也就沒辦法設計實驗或蒐集資料來回答它。把它拆小，每一小題只改變一個量、測量一個量，才知道要準備什麼器材、記錄什麼數據。大問題沒有錯，它是起點。

</StudentAsks>

<Perspective title="換個角度：拿跨科概念當提問清單">

上面是「先選學科，再找問題」。也可以反過來：先拿跨科概念，再看每個問題要哪幾科來回答。

1. **物質與能量**：營火的能量從哪裡來、到哪裡去？木柴裡的碳呢？這一題要物理（核融合、熱）、生物（光合作用）和化學（燃燒）一起回答。
2. **系統與尺度**：一堆營火和整個地球的大氣，是不是同一個尺度的問題？這要化學加上地科（氣候變遷）。
3. **改變與穩定**：火燒完以後，什麼可以回到原狀，什麼回不去？這要物理（能量降級）和化學（燃燒）。
4. **交互作用**：火和周圍的空氣怎麼互相影響？火消耗周圍的氧，也加熱了周圍的空氣。

從學科出發，問題比較窄，容易驗證；從跨科概念出發，一個問題就跨好幾科，正好找出學科之間的接點。兩者並用。

</Perspective>

## 二、物質與能量：跟著能量走一趟

四科的答案各自正確，但還不是一個解釋。把它們接起來的第一條線，是跟著能量走：

1. **太陽**：太陽的能量來自<Term t="physics.nuclear-fusion">核融合</Term>，以光的形式射到地球（[質能互換與核能](/zh-tw/physics/s116-mass-energy-nuclear/)）。
2. **樹**：光合作用把光能存進葡萄糖等有機物；木柴裡的纖維素就是由許多葡萄糖連成的（[ATP與光合、呼吸作用](/zh-tw/biology/s116-cell-energy/)、[生活中的有機物質](/zh-tw/chemistry/s116-organic-life/)）。
3. **燃燒**：木柴和氧反應，放出化學能。固體只在表面反應，同樣質量時，細樹枝的接觸面積大，和氧反應得比較快（[接觸面積、反應速率與先進科技](/zh-tw/chemistry/s116-rate-and-technology/)）。
4. **熱**：<Term t="physics.heat">熱</Term>自發地由高溫的火焰流向較冷的人和空氣（[溫度、熱與能量的品質](/zh-tw/physics/s116-heat-energy-quality/)）。

對每一支箭頭說出：這一步是哪一科、哪一章的觀念？能量在這一步是什麼樣子？最後看箭頭④：散到周圍空氣的熱，能不能自己倒流回來，把火重新點著？

<StudentAsks q="能量最後散到空氣裡，是不是就用完、不見了？這樣不就違反能量守恆？">

沒有違反。能量的總量一焦耳都沒少，只是變得很分散：周圍的空氣只溫熱了一點點，再也聚不回來點火。這就是物理說的能量降級：能量守恆，作功的能力卻越用越低。「用完」的是能量的品質，不是能量本身。

</StudentAsks>

## 三、系統與尺度：一堆營火和整個地球

地科那一題問：木柴和煤裡的碳，各是多久以前離開大氣的？知道碳會繞一圈以後，就能查資料回答它：

- 木柴的碳，是這棵樹活著的時候，用光合作用從大氣拿來的。
- 煤是死去的生物埋在地下、經過幾百萬年才形成的，它的碳離開大氣已經幾百萬年。燃燒化石燃料，卻在一兩百年內把大量的碳送回大氣，大氣的二氧化碳就增加了（[環境汙染、永續發展與能源](/zh-tw/chemistry/s116-environment-energy/)）。

數線上每往右一格，時間就乘以10。比一比：煤的碳離開大氣花了「數百萬年」，燒化石燃料把它送回去只要「近百年」，兩者隔了幾格？大約四格半，也就是說，碳回到大氣，比它當初被鎖進地下快了好幾萬倍。

地科的[氣候變遷](/zh-tw/earth/s116-climate-change/)一章說：長期的自然因素無法完全解釋近期的快速暖化，目前的證據顯示，人類活動是主要因素，其中燃燒化石燃料使大氣中的二氧化碳增加，<Term t="chemistry.greenhouse-effect">溫室效應</Term>增強。

<StudentAsks q="營火也會放出二氧化碳，那露營是不是暖化的主因？">

「主因」說的是整個地球、近百年這個尺度。要判斷某件事是不是主因，得先把尺度對齊：在地球的尺度上比較各種來源各有多少、對不對得上暖化的時間，不能只看眼前這一堆火。一堆營火只燒一晚，落在數線的最左邊，是一個小系統；暖化是整個地球這個大系統的問題；這就是系統與尺度這個跨科概念要提醒你的事。

</StudentAsks>

## 四、第二個情境：池塘的一天

校園的池塘裡長滿藻類和水草。某生把感測器放進池水，每4小時記錄一次池水中的二氧化碳（相對值）和pH，從半夜0時量到隔天0時（24時）。這次用的跨科概念是「改變與穩定」和「交互作用」。

四科各解釋一段：

- **生物**：白天光合作用和呼吸作用同時進行，光合作用較快，水中的二氧化碳減少；夜裡只剩呼吸作用，二氧化碳回升。
- **化學**：$\ce{CO2 + H2O <=> H2CO3}$，溶在水中的二氧化碳使水偏酸。二氧化碳變少，碳酸就少，pH上升。
- **地科**：晝夜來自地球自轉。北半球夏天晝長夜短，冬天晝短夜長（[恆星的視運動與太陽的季節位置](/zh-tw/earth/s116-sky-motion/)），所以可以預測：夏天二氧化碳下降的時段比冬天長。
- **物理**：池水吸收陽光而變暖；夜裡若空氣比池水冷，熱就由池水流向空氣。

<StudentAsks q="晚上二氧化碳變多，是因為藻類到晚上才開始呼吸嗎？">

不是。呼吸作用白天、晚上都在進行。白天光合作用比呼吸作用快，蓋過了它，二氧化碳的淨變化是減少；晚上沒有光，只剩呼吸作用，二氧化碳才看得出在增加。這是生物「ATP與光合、呼吸作用」一章讀二氧化碳圖時的同一個道理。

</StudentAsks>

不畫圖也能讀出趨勢：像[論證與建模](/zh-tw/inquiry/s116-inq-argue-model/)一章那樣，把相鄰兩次的二氧化碳相減，列出差值（每一格變了多少）。

| 時段（時） | 變化（相對值） |
|---|---|
| 0→4 | ＋2 |
| 4→8 | −3 |
| 8→12 | −5 |
| 12→16 | −2 |
| 16→20 | ＋4 |
| 20→24 | ＋4 |

1. **正負號**告訴你方向：4時以後變成負的，表示開始減少；16時以後變成正的，表示開始增加。由負轉正的地方就是最低點，也就是16時。
2. **大小**告訴你快慢：−5最大，所以8→12這一段減少得最快，和圖上最陡的一段一致。
3. 最後一格也值得看：24時回到14，和0時一樣。一天之內一直在變，一天一天來看卻很穩定，這就是「改變與穩定」。

## 五、接成一個解釋，再提出結論

四段答案接起來，就是一條因果鏈：地球自轉使池塘有晝夜（地科）；白天有光，光合作用吸收二氧化碳的速率大於呼吸作用（生物）；水中二氧化碳減少，碳酸變少，pH上升（化學）；傍晚以後光變弱，夜裡只剩呼吸作用，二氧化碳回升、pH下降，隔天再重複一次。

讀圖：實線箭頭是我們的解釋。那條虛線代表另一種可能：白天水溫也上升，會不會是水溫讓pH上升的？光和水溫在白天一起上升，光看這組數據，分不出是哪一個。

**結論要說到證據為止**。這組示意數據支持的結論是：「在這個池塘、這一天，二氧化碳在16時最少、pH在16時最高，和光合作用與呼吸作用的消長一致。」它沒有說「所有池塘都是16時」，也沒有說已經排除了水溫的影響。

<Perspective title="用對立解釋檢驗結論">

要讓結論更站得住，就要正面處理虛線那個對立解釋：pH上升是水溫造成的。

設計一個公平的比較：

1. 取同一個池塘的水和藻類，分裝在兩個相同的水槽，放進同一盆溫水裡，讓兩槽的水溫一直相同。
2. 一槽照光，另一槽用不透光的蓋子蓋住。
3. 改變的量：有沒有光。測量的量：pH。保持不變：水溫、水量、藻類的量、一開始的pH。

如果只有照光的那一槽pH上升，水溫就解釋不了這個變化，我們的解釋更站得住；如果兩槽一起上升，就要修改解釋。

多出來的一步是：先把對手的說法寫出來，再設計一個只有它會失敗的實驗。

</Perspective>
