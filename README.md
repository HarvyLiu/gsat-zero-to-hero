# 學測從零開始 · GSAT from Zero

A free, bilingual (繁體中文 ⇄ English) course website for Taiwan's 學測 (GSAT). It covers 數學 (數A and 數B); 自然 (物理, 化學, 生物, 地球科學 and 探究與實作); 社會 (歷史, 地理, 公民與社會); and 國文 as a beta.

Every chapter opens and closes with a short teacher–student dialogue, in the style of OSTEP's dialogues. The layout and drawing style follow the owner's ASMC project: graph paper with one even, thin grid, isometric drawings and cards. The colours are this site's own "answer sheet + red pen" theme: cream paper, navy ink, a vermilion 朱紅 accent, indigo links and a highlighter yellow. The logo and heading markers are isometric open books.

The site name and the character names are placeholders until the owner chooses them.

> **Status: framework (S0).** No lesson content is published yet. Content is written in batches through the verification pipeline (`docs/plan.md`, "Accuracy system").

## The rules this project enforces

- **No jumps.** A chapter may only use ideas taught in itself or in a chapter it depends on. This is checked across subjects by `tests/curriculum/no-jump.test.ts`.
- **Nothing invented.** Every chapter cites sources from `src/data/registry/sources.json`. Exam facts, laws and other time-sensitive values live in `src/data/registry/facts.json`, each with an as-of date and a review-by date. Past 學測 papers are **linked, never copied**, and practice items are original.
- **Full coverage.** Every official 108課綱 學習內容 code in 學測 scope must be taught by some chapter, on the correct 數A/數B path. Codes come from the frozen, verified research in `research/`.
- **Language parity.** Every lesson exists in `zh-tw` and `en` with the same interactive items. English pages show the Chinese term at first use, e.g. "real number（實數）".

## Run it

PowerShell or bash, from this folder:

```bash
npm install
```

```bash
npm run dev
```

The dev server runs at http://localhost:4331. Port 4321 is left free for the ASMC project.

```bash
npm test
```

```bash
npm run build
```

```bash
npm run preview
```

`npm run build` builds the static site in `dist/` and the Pagefind search index. `npm run preview` serves `dist/` at http://localhost:4332; search only works there, not in dev.

The Python verification harness recomputes every practice-item answer key:

```bash
harness/.venv/Scripts/python -m pytest harness
```

The harness virtual environment is created once with:

```bash
python -m venv harness/.venv && harness/.venv/Scripts/python -m pip install pyyaml sympy pytest
```

## Where things live

| Path | What it is |
| --- | --- |
| `docs/plan.md` | The approved plan: scope, milestones, the accuracy system |
| `docs/design/` | Frozen design outputs (course maps, pipeline, platform) and the critique that overrides them |
| `research/verified-2026-11-15.json` | Frozen research: 12 researchers and 12 adversarial fact-checkers, from primary sources. Read-only input. |
| `src/data/schema.ts` | Zod data contracts for every registry, course file and item bank |
| `src/data/registry/` | Codes (generated by `npm run import:codes`), sources, licences, facts, misconceptions, exam data |
| `src/data/course/<subject>.json` | Course outlines (single source of truth per subject) |
| `src/data/terms/` | Glossary and concept registry (zh/en term, definition, term source) |
| `src/data/items/` | Practice item banks (YAML), shared by the site and the Python harness |
| `src/content/lessons/{zh-tw,en}/<subject>/<slug>.mdx` | Lessons, mirrored per language |
| `src/plugins/remark-dialogue.ts` | Turns ```` ```dialogue ```` blocks into chat bubbles |
| `harness/` | Python/SymPy verification of answer keys |
